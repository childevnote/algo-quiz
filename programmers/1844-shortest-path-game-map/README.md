# 게임 맵 최단거리

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/1844
- 레벨: Lv.2
- 카테고리: DFS/BFS
- 풀이 날짜: 2026-10-30 (18:00 자동 풀이)

## 문제 핵심 요약

0(벽)과 1(길)로 이루어진 n x m 격자 맵에서, 왼쪽 위 (1, 1) 칸에서 출발해 상하좌우로 한 칸씩 이동하며 오른쪽 아래 (n, m) 칸까지 도달할 때 지나가는 칸 개수의 최솟값을 구하는 문제다. 도달할 수 없으면 -1을 반환한다.

- 제한사항: n, m은 1 이상 100 이하 (단, 둘 다 1인 경우는 없음), maps는 0과 1로만 구성
- 입출력 예: 5x5 예시 맵 → 11 / 도착 불가능한 변형 맵 → -1

## 문제 분석 및 핵심 로직

이동 비용이 모든 칸에서 동일하고(한 칸 이동 = 1), 지나간 칸 수의 최솟값을 묻는 문제이므로 너비 우선 탐색(BFS)이 곧 최단 거리다. BFS는 시작점에서 가까운 칸부터 순서대로 방문하기 때문에, 목표 칸에 처음 도착한 순간의 거리가 그 칸까지의 최단 거리가 된다. 목표 칸에 도착하는 즉시 반환하면 남은 탐색을 생략할 수 있다.

핵심은 "거리"를 어디에 저장하느냐이다. 방문 여부를 따로 두고 거리를 별도로 계산하면 목표 칸까지의 거리를 재구성하는 과정이 필요해진다. 대신 방문 여부를 거리 배열 하나로 겸하면, 처음 방문하는 순간 기록되는 값이 곧 최단 거리가 된다. 시작 칸의 거리는 지나간 칸이 1개이므로 1로 초기화하고, 이웃 칸으로 이동할 때마다 거리에 1을 더해 기록한다. 큐가 비도록 목표 칸에 도달하지 못하면 도달 불가능하므로 -1을 반환한다.

## 개념별 심층 설명

### 너비 우선 탐색(BFS) — 같은 깊이부터 전부 탐색

BFS는 시작점에서 한 번 이동해 갈 수 있는 칸을 모두 방문한 뒤, 그다음 두 번 이동해 갈 수 있는 칸을 방문하는 식으로, 거리 순서대로 칸을 확장한다. 큐(선입선출)를 사용해 먼저 들어간 칸부터 처리하기 때문에 이 순서가 유지된다.

초심자 방식은 보통 모든 경로를 끝까지 따라가 보는 깊이 우선 탐색(DFS)으로 접근한다. DFS도 모든 경로를 탐색하면 최단 거리를 찾을 수 있지만, 최단 경로가 아닌 긴 경로까지 모두 탐색해야 하므로 불필요한 탐색이 많아진다. 개선 방식은 BFS로, 목표 칸에 처음 도착하는 순간이 곧 최단 거리이므로 그 즉시 탐색을 멈출 수 있다. 이 문제처럼 간선 가중치가 모두 같은 격자에서는 BFS 한 번으로 최단 거리가 확정된다.

### 거리 배열로 방문 여부 겸하기

일반적인 BFS는 `visited` 불리언 배열을 따로 두지만, 이 문제에서는 거리 자체가 방문 기록 역할을 한다. 거리 배열을 -1로 초기화해 두면 -1인 칸은 미방문, -1이 아닌 칸은 이미 방문했고 그 값이 최단 거리다. 처음 방문할 때 기록되는 거리가 최단 거리인 이유는 BFS의 거리 순 확장 때문이다. 시작 칸을 0이 아니라 1로 두는 것은 답이 "지나간 칸의 개수"이지 "이동 횟수"가 아니기 때문이다. 예를 들어 2x2 전부 길인 맵에서는 이동 2번으로 3칸을 지나므로 답은 3이다.

### 도달 불가능 판정

목표 칸이 벽으로 둘러싸여 있으면 BFS 큐가 비게 된다. 이 경우 거리 배열의 목표 칸 값은 -1 그대로이므로, 탐색 종료 후 -1을 반환한다. 큐가 비었다는 것은 도달 가능한 모든 칸을 다 방문했다는 뜻이라, 더 탐색할 여지가 없다.

## 최종 솔루션 코드

### Python

```python
from collections import deque

def solution(maps):
    n, m = len(maps), len(maps[0])
    # 1. 방문 거리 배열: -1은 미방문, 시작 칸(0, 0)은 지나간 칸 1개로 초기화
    dist = [[-1] * m for _ in range(n)]
    dist[0][0] = 1
    # 2. BFS 큐: 시작 위치에서 출발
    queue = deque([(0, 0)])
    # 3. 네 방향 이동
    directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    while queue:
        x, y = queue.popleft()
        # 4. 목표 칸에 도달하면 그 즉시 거리가 최단 거리
        if x == n - 1 and y == m - 1:
            return dist[x][y]
        for dx, dy in directions:
            nx, ny = x + dx, y + dy
            # 5. 맵 안쪽, 벽이 아니고, 아직 방문하지 않은 칸만 이동
            if 0 <= nx < n and 0 <= ny < m and maps[nx][ny] == 1 and dist[nx][ny] == -1:
                dist[nx][ny] = dist[x][y] + 1
                queue.append((nx, ny))

    # 6. 큐가 비도록 목표 칸에 도달하지 못하면 -1
    return -1
```

### Java

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int solution(int[][] maps) {
        int n = maps.length;
        int m = maps[0].length;
        // 1. 방문 거리 배열: -1은 미방문, 시작 칸(0, 0)은 지나간 칸 1개로 초기화
        int[][] dist = new int[n][m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                dist[i][j] = -1;
            }
        }
        dist[0][0] = 1;
        // 2. BFS 큐: 시작 위치에서 출발
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0});
        // 3. 네 방향 이동
        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int x = cur[0], y = cur[1];
            // 4. 목표 칸에 도달하면 그 즉시 거리가 최단 거리
            if (x == n - 1 && y == m - 1) {
                return dist[x][y];
            }
            for (int[] d : directions) {
                int nx = x + d[0], ny = y + d[1];
                // 5. 맵 안쪽, 벽이 아니고, 아직 방문하지 않은 칸만 이동
                if (nx >= 0 && nx < n && ny >= 0 && ny < m
                        && maps[nx][ny] == 1 && dist[nx][ny] == -1) {
                    dist[nx][ny] = dist[x][y] + 1;
                    queue.offer(new int[]{nx, ny});
                }
            }
        }

        // 6. 큐가 비도록 목표 칸에 도달하지 못하면 -1
        return -1;
    }
}
```

## 요약

균일 비용 격자의 최단 경로는 BFS로 푼다. 거리 배열을 -1로 초기화해 방문 여부와 최단 거리를 겸하고, 시작 칸을 1로 두어 지나간 칸 개수를 직접 세며, 목표 칸에 처음 도착하는 순간 반환한다. 도달하지 못하면 큐가 비는 것으로 -1을 판정한다.
