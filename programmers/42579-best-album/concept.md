# 개념 정리 — 베스트앨범 풀이에 필요한 개념

## 해시 맵(Hash Map)

키와 값을 짝지어 저장하는 자료구조다. 키를 해시 함수로 변환해 저장 위치를 계산하므로, 키로 값을 찾거나 삽입·갱신하는 연산이 평균적으로 O(1) 시간에 수행된다.

일반적인 예시: 과목별 점수를 누적할 때는 과목 이름을 키로, 점수 합을 값으로 두는 해시 맵을 만든다. 데이터를 한 번 순회하면서 각 항목의 키에 해당하는 값을 더해 가면, 그룹별 합계를 한 번의 순회로 구할 수 있다.

```python
from collections import defaultdict

totals = defaultdict(int)  # 없는 키에 접근하면 0으로 초기화
for key, value in [("a", 10), ("b", 5), ("a", 20)]:
    totals[key] += value
# totals == {"a": 30, "b": 5}
```

키가 없을 때 기본값을 자동 생성하는 형태(`defaultdict`, Java의 `computeIfAbsent`/`merge`)를 쓰면 "키가 존재하는지 검사"하는 분기를 줄일 수 있다.

## 그룹화(Grouping)

여러 항목을 공통 속성 기준으로 묶는 작업이다. 해시 맵에 속성을 키로 두고, 해당 속성을 가진 항목들을 값으로 쌓으면 된다. 한 번의 순회로 끝낼 수 있어, 속성 종류마다 전체를 다시 훑는 방식보다 효율적이다.

## 다중 기준 정렬(Multi-key Sort)

정렬 기준이 여러 개일 때, 기준을 우선순위 순서대로 묶어 하나의 비교 규칙으로 만든다. 첫 번째 기준이 동점일 때만 다음 기준으로 비교한다.

Python에서는 정렬 키를 튜플로 표현한다. 튜플은 첫 번째 원소부터 순서대로 비교되므로, 원하는 우선순위대로 원소를 나열하면 된다. 내림차순이 필요한 숫자 기준에는 마이너스를 붙인다.

```python
data = [(100, 2), (200, 1), (100, 0)]
# 첫 번째 값 내림차순, 두 번째 값 오름차순
sorted(data, key=lambda x: (-x[0], x[1]))
# [(200, 1), (100, 0), (100, 2)]
```

Java에서는 `Comparator`를 직접 작성한다. 첫 번째 기준이 다르면 그 차이로, 같으면 다음 기준으로 비교 결과를 반환한다.

```java
list.sort((a, b) -> a[0] != b[0] ? b[0] - a[0] : a[1] - b[1]);
```

## 상위 k개 선택(Top-k Selection)

목록에서 가장 큰(또는 작은) k개만 뽑는 작업이다. 목록 전체를 정렬하면 O(n log n)이 걸린다. k가 작고 n이 클 때는 크기 k인 힙을 유지하는 방법이 유리하다. 힙에 원소를 넣을 때마다 가장 작은 원소와 비교해 교체 여부를 판단하므로 O(n log k) 시간에 끝나고, 공간도 O(k)만 사용한다. 다만 k가 목록 크기에 비해 크지 않거나 코드의 단순함이 중요할 때는 전체 정렬 후 앞부분을 자르는 방식도 충분히 실용적이다.
