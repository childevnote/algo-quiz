# 개념 노트: 정렬 + 한 번의 스캔

이 문제 풀이에 쓰인 개념 정리. 일반 예시만 담는다.

## 1. 정렬로 순서 관계를 고정하기

정렬의 힘은 "i번째 원소"에 확정된 의미를 부여한다는 데 있다. 내림차순 정렬된 배열에서 i번째(1-indexed) 원소는 "상위 i개 중 가장 작은 값"이다. 이 성질 덕분에 "상위 i개가 어떤 조건을 만족하는가"라는 집합 단위의 질문을 "i번째 원소가 조건을 만족하는가"라는 원소 단위의 질문으로 바꿀 수 있다.

일반 예시:

```python
scores = sorted([82, 95, 71, 90], reverse=True)  # [95, 90, 82, 71]
# scores[2] = 82 → "상위 3명의 최저 점수는 82점"
# 즉, "90점 이상인 사람이 2명 이상인가?"는 scores[1] >= 90 한 줄로 판정
```

## 2. 단조성을 이용한 조기 종료

배열이 정렬되어 있고, 검증하려는 조건이 단조적(한 번 깨지면 뒤에서도 계속 깨짐)이면, 첫 실패 지점에서 스캔을 멈춰도 정답에 영향을 주지 않는다. 내림차순 배열에서 "원소 값 >= 인덱스" 같은 형태가 대표적이다. 선형 스캔의 조기 종료는 정확성 증명이 함께 있어야 안전하므로, "뒤의 원소는 전부 더 작다"는 단조성을 명시적으로 확인하는 습관이 중요하다.

일반 예시:

```python
arr = [9, 7, 5, 3, 1]  # 내림차순
count = 0
for i, v in enumerate(arr, start=1):
    if v >= i:
        count += 1
    else:
        break  # 이 뒤의 v는 모두 더 작으므로 조건 회복 불가
```

## 3. 후보 검증 vs. 스캔 — 복잡도 관점

후보를 하나씩 잡고 전체 배열을 검사하면 O(n²)이 되기 쉽다. 이때 배열을 정렬해 두면 각 후보의 검증이 O(1)로 떨어지고, 전체가 O(n log n)이 된다. "모든 후보를 다 봐야 한다"는 발상이 나오면, 후보를 정렬 순서로 재배열해 한 번의 패스로 바꿀 수 있는지 먼저 따져본다.
