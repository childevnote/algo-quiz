# 카펫 — [Lv.2 · 완전탐색]

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42842
- 풀이 날짜: 2026-10-22 (18시 자동 풀이)

## 문제 핵심 요약

테두리 1줄은 갈색, 중앙은 노란색인 격자 카펫이 있다. 갈색 격자 수(brown)와 노란색 격자 수(yellow)만 주어질 때 전체 카펫의 [가로, 세로]를 구하라. 카펫의 가로는 세로와 같거나 길다.

- 제한사항: brown은 8 이상 5,000 이하, yellow는 1 이상 2,000,000 이하의 자연수
- 입출력 예: brown=10, yellow=2 → [4, 3] / brown=8, yellow=1 → [3, 3] / brown=24, yellow=24 → [8, 6]

## 문제 분석 및 핵심 로직

그림에서 갈색은 테두리 한 겹이므로, 노란 영역을 가로 `w`, 세로 `h`인 직사각형이라고 두면 전체 카펫은 가로 `w+2`, 세로 `h+2`가 된다. 노란 영역의 넓이는 `w × h = yellow`이고, 전체 넓이는 `(w+2) × (h+2) = brown + yellow`다. 노란 영역의 넓이가 고정되어 있으므로 가능한 내부 크기는 yellow의 약수쌍뿐이고, 그중 전체 넓이가 brown + yellow와 일치하는 쌍이 정답이다. 문제를 "외부 차원을 전부 뒤지는 탐색"이 아니라 "약수쌍 몇 개 중 하나를 고르는 선택"으로 바꾸는 게 핵심이다.

## 개념별 심층 설명

### 초심자 방식: 전체 격자 크기 전부 탐색

갈색과 노란색 합(total = brown + yellow)의 약수쌍을 전부 구해 전체 가로/세로 후보로 삼고, 각 후보마다 노란 영역이 yellow가 되는지 확인하는 방식이다. total이 최대 2,005,000이라 약수쌍 개수는 작아 동작은 하지만, "노란 영역을 먼저 고정한다"는 문제의 구조를 활용하지 못한다.

### 개선 방식: 노란 영역의 약수쌍만 탐색

yellow의 약수쌍 (h, w)만 돌면서 전체 넓이 조건을 확인한다. 루프는 `h = 1`부터 `√yellow`까지로 끝나며, 한 쌍만 통과하면 끝이다. 이 풀이의 핵심 로직은 두 가지다.

1. **약수쌍으로 탐색 공간 축소**: 전체 차원의 약수쌍이 아니라 노란 영역의 약수쌍만 본다. 약수쌍에서 `w ≥ h`가 되도록 `w = yellow / h`로 잡으면 전체 차원 `[w+2, h+2]`는 자동으로 가로 ≥ 세로 조건을 만족한다.
2. **전체 넓이로 정답 판정**: 후보 쌍에 대해 `(w+2) × (h+2) == brown + yellow`인지를 본다. 노란 넓이가 이미 yellow로 고정되어 있으니 갈색 조건은 전체 넓이 조건 하나로 대체된다.

### 왜 약수쌍의 작은 쪽을 세로로 두는가

루프 변수 `h`가 1부터 `√yellow`까지 돌면 `w = yellow / h ≥ h`가 보장된다. 따라서 반환되는 `[w+2, h+2]`는 항상 가로가 세로보다 크거나 같아 "가로 ≥ 세로" 제한을 별도로 검사할 필요가 없다. 문제에 정답이 하나로 보장되므로 첫 매칭에서 중단해도 된다.

## 최종 솔루션 코드

### Python

```python
def solution(brown, yellow):
    # 노란 영역은 안쪽 직사각형 (가로 w, 세로 h)
    # 전체 가로 = w+2, 세로 = h+2 (테두리 갈색 1줄씩)
    for h in range(1, int(yellow ** 0.5) + 1):
        if yellow % h == 0:
            w = yellow // h              # ① 노란 영역의 약수쌍 = 가능한 내부 가로/세로
            if (w + 2) * (h + 2) == brown + yellow:  # ② 전체 격자 수와 일치하는 쌍 채택
                return [w + 2, h + 2]
    return []
```

### Java

```java
class Solution {
    public int[] solution(int brown, int yellow) {
        int[] answer = new int[2];
        // 노란 영역은 안쪽 직사각형 (가로 w, 세로 h)
        // 전체 가로 = w+2, 세로 = h+2 (테두리 갈색 1줄씩)
        for (int h = 1; h <= Math.sqrt(yellow); h++) {
            if (yellow % h == 0) {
                int w = yellow / h; // ① 노란 영역의 약수쌍 = 가능한 내부 가로/세로
                if ((w + 2) * (h + 2) == brown + yellow) { // ② 전체 격자 수와 일치하는 쌍 채택
                    answer[0] = w + 2;
                    answer[1] = h + 2;
                    break;
                }
            }
        }
        return answer;
    }
}
```

## 학습 노트

- 막혔던 점: 자동 풀이라 세션 중 막힘은 없었음. 주의할 지점은 약수쌍에서 가로/세로 순서를 반대로 잡으면 [세로, 가로] 순으로 반환되어 예제가 깨진다는 것.
- 핵심 포인트: 테두리 한 겹이라는 조건 덕분에 내부 영역이 직사각형으로 확정되고, 문제는 yellow의 약수쌍 찾기 하나로 환원된다.
- 개선: 약수쌍 탐색 범위를 1..yellow가 아니라 1..√yellow로 줄였다. yellow=2,000,000 기준으로 최대 1414회 반복이면 끝난다.

## 성능 측정 (로컬 실측)

- 예제 케이스 3건(brown=10/8/24, yellow=2/1/24): 모두 정답, 실행시간 무시할 수준
- 최악 케이스(yellow=1,999,993 ≈ 소수, brown=5000) 1000회 평균: 약 0.074ms/회 — 한계 입력에서도 한 번의 호출이 0.1ms에 못 미친다
- 메모리: 1000회 반복 기준 피크 약 0.22KB — 입력 크기와 무관하게 상수 메모리만 사용
- 시간 복잡도: O(√yellow) — yellow ≤ 2,000,000이므로 최대 약 1414회 반복
- 공간 복잡도: O(1)

## 요약

테두리 1줄 조건에서 내부 노란 영역을 직사각형으로 확정 짓고, yellow의 약수쌍을 √yellow까지만 탐색하면서 전체 넓이가 brown + yellow와 일치하는 쌍을 고르는 완전탐색 풀이. 시간 O(√yellow), 공간 O(1)로 최악 케이스도 0.1ms 미만이다.
