# 개념 정리 — 카펫 (약수쌍 완전탐색)

이 문제에 필요한 일반 개념만 정리한다.

## 약수쌍 (divisor pairs)

자연수 n의 약수쌍은 곱이 n이 되는 두 수의 쌍 (a, b)이다. a가 1부터 √n까지만 돌면서 n % a == 0인지 보면 모든 약수쌍을 빠짐없이 구할 수 있다. 예를 들어 12의 약수쌍은 (1, 12), (2, 6), (3, 4) 세 개다. 범위를 √n까지로 두는 이유는 a와 n/a가 서로 대칭이라 절반만 보면 되기 때문이다.

```python
def divisor_pairs(n):
    pairs = []
    for a in range(1, int(n ** 0.5) + 1):
        if n % a == 0:
            pairs.append((a, n // a))
    return pairs
```

완전제곱수인 경우 (4, 4)처럼 a == b인 쌍이 하나 생기는 점에 유의한다.

## 탐색 공간 축소

가능한 후보가 전부 탐색 대상인 완전탐색이라도, 후보를 무엇으로 잡느냐에 따라 탐색 공간이 크게 달라진다. 예를 들어 "넓이가 n인 직사각형의 가능한 가로/세로"를 전부 열거하는 대신, "약수쌍"만 열거하면 탐색 범위가 n에서 √n으로 줄어든다. 후보 조건을 미리 고정(노란 영역 넓이 = yellow)시켜 두면 판정식도 하나(전체 넓이 비교)로 줄어드는 식이다.

## 가로/세로 순서 고정

직사각형 문제에서 "가로는 세로보다 크거나 같다"는 조건이 있을 때, 약수쌍에서 작은 수를 세로·큰 수를 가로로 약속해 두면 조건을 별도로 검사하지 않아도 된다. `h ≤ √n` 범위로 돌고 `w = n / h`를 취하면 `w ≥ h`가 자동 보장된다.
