# 해시맵과 빈도 세기

## 1. 해시맵

- 키를 해시 함수로 변환해 저장 위치를 계산하는 자료구조
- 조회·삽입·삭제: 평균 O(1)
- Python: `dict` / Java: `java.util.HashMap`

## 2. 빈도 세기 패턴

- "같은 값이 몇 번 등장했는가"를 셀 때 `값 → 횟수` 형태로 누적하는 정석 패턴
- Python: `collections.Counter`
  - `Counter(items)`로 한 번에 집계
  - `subtract`로 다른 집계 결과만큼 차감 가능
- Java: `map.getOrDefault(key, 0) + 1`
  - 없는 키 조회 시 기본값을 반환하므로 초기화 분기가 필요 없음

## 3. 시간복잡도

- 리스트에서 탐색·삭제를 반복하면 O(n²): n=100,000일 때 시간 초과
- 해시맵에 누적하면 전체를 한 번씩만 훑으므로 O(n)

## 4. 중복 키 처리

- 횟수로 관리하면 같은 키가 여러 번 등장해도 자연스럽게 처리됨
- "존재 여부"가 아닌 "횟수"로 생각하는 것이 핵심
