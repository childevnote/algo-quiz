## 문제 핵심 요약

n명의 선수가 1대1 경기를 치른다. A가 B보다 강하면 A는 B를 항상 이긴다. 일부 경기 결과만 주어졌을 때, 정확히 몇 위인지 확정할 수 있는 선수가 몇 명인지 구한다.

핵심 제한사항:

- 선수 수 n은 1 이상 100 이하
- 경기 결과는 1개 이상 4,500개 이하
- results의 각 행 [A, B]는 A가 B를 이겼다는 의미
- 모든 경기 결과에 모순이 없음

입출력 예:

| n | results | return |
|---|---------|--------|
| 5 | [[4, 3], [4, 2], [3, 2], [1, 2], [2, 5]] | 2 |

예 설명: 2번 선수는 [1, 3, 4] 선수에게 지고 5번 선수에게 이겼으므로, 다른 네 선수와의 승패가 모두 정해져 4위가 확정된다. 5번 선수는 4위인 2번 선수에게 졌으므로 5위가 확정된다. 답은 2명이다.

## 문제 분석 및 핵심 로직

순위가 확정된다는 말은, 그 선수의 위·아래가 모두 정해진다는 뜻이다. 다른 선수 j에 대해 직접 붙은 적이 없어도 간접 관계로 승패를 알 수 있다. 예를 들어 A가 B를 이기고 B가 C를 이겼다면, A가 C를 이긴다는 사실이 따라 나온다. 즉 승패 관계는 전이적이다.

따라서 문제는 이렇게 바뀐다. 직접 경기 결과로 만든 승패 방향 그래프에서, 전이적 폐쇄(transitive closure)를 구한 뒤 각 선수마다 다른 모든 선수와 승패가 연결되어 있는지 확인한다. 연결된 선수가 n-1명이면 그 선수의 순위는 확정이다.

핵심 로직은 세 단계다.

1. 승패 관계 행렬을 만든다. `win[i][j]`는 i번 선수가 j번 선수를 이긴다는 뜻이다.
2. 플로이드-워셜로 전이적 폐쇄를 계산한다. i가 k를 이기고 k가 j를 이기면 i는 j를 이긴다.
3. 각 선수마다 이기거나 진 상대의 수가 n-1명인지 세어 답을 구한다.

## 개념별 심층 설명

### 1. 전이적 폐쇄 — 직접 관계만으로는 부족하다

초심자 방식은 직접 붙은 경기만으로 판단하는 것이다. A가 B를 이겼다는 기록이 없으면 둘의 우열을 모른다고 본다. 이 방식으로는 예시의 2번 선수를 판정할 수 없다. 2번은 1번, 3번, 4번에게 직접 졌지만 5번과는 직접 붙지 않았다. 2번이 5번을 이겼다는 기록은 주어진 다섯 경기 중 [2, 5]에 직접 있으므로 이 경우는 되지만, 일반적으로는 한두 단계 건너뛴 관계가 숨어 있다.

개선 방식은 간접 관계까지 전부 펼치는 것이다. "A가 B를 이기고 B가 C를 이기면 A는 C를 이긴다"는 규칙을 모든 선수 삼중항에 적용하면, 직접 기록에 없던 승패까지 채울 수 있다. 이렇게 완성된 관계를 전이적 폐쇄라고 한다.

### 2. 플로이드-워셜 — 세 겹 반복으로 간접 관계를 채운다

전이적 폐쇄를 구하는 가장 직관적인 방법은 플로이드-워셜이다. 중간 경유점 k를 하나씩 고정하고, i → k → j 경로가 존재하면 i → j를 연결한다. k를 1번부터 n번까지 순서대로 늘려 가면, k를 거치는 모든 간접 경로가 행렬에 반영된다.

동작 원리를 작은 예로 보자. A가 B를 이기고 B가 C를 이겼다고 하자. k=B인 단계에서 i=A, j=C를 보면 win[A][B]와 win[B][C]가 모두 참이므로 win[A][C]가 참이 된다. k가 커질수록 더 긴 간접 경로도 같은 방식으로 채워진다. 한 번의 k 단계가 끝나면 그 k를 경유하는 모든 간접 승패가 확정되므로, k를 끝까지 돌리면 폐쇄가 완성된다.

n이 최대 100이라 세 겹 반복은 100³ = 1,000,000번의 연산으로 끝나고, results가 최대 4,500개라도 충분히 여유가 있다.

### 3. 순위 확정 판정 — 이기든 지든, 연결만 되면 된다

순위가 확정되려면 다른 모든 선수와 승패가 정해져야 한다. i가 j를 이겼든(i → j) 졌든(j → i) 상관없다. 어느 한쪽 방향으로라도 연결되어 있으면 두 선수의 우열은 확정이다. 반대로 어느 방향으로도 연결되지 않은 선수가 한 명이라도 있으면, 그 선수와의 순서를 정할 수 없어 i의 순위는 확정되지 않는다.

그래서 판정은 단순하다. 각 선수 i마다 j ≠ i인 모든 j에 대해 win[i][j] 또는 win[j][i]가 참인지 세고, 개수가 n-1이면 카운트한다.

## 최종 솔루션 코드

### Python

```python
def solution(n, results):
    # 1. 승패 관계 행렬: win[i][j] = i번 선수가 j번 선수를 이김 (0-indexed)
    win = [[False] * n for _ in range(n)]
    for a, b in results:
        win[a - 1][b - 1] = True

    # 2. 플로이드-워셜로 승패 관계의 전이적 폐쇄 계산
    #    i가 k를 이기고 k가 j를 이기면 i는 j를 이긴다
    for k in range(n):
        for i in range(n):
            if win[i][k]:
                row_i = win[i]
                row_k = win[k]
                for j in range(n):
                    if row_k[j]:
                        row_i[j] = True

    # 3. 다른 모든 선수와 승패가 확정된 선수 카운트
    answer = 0
    for i in range(n):
        count = 0
        for j in range(n):
            if i == j:
                continue
            if win[i][j] or win[j][i]:
                count += 1
        if count == n - 1:
            answer += 1
    return answer
```

### Java

```java
class Solution {
    public int solution(int n, int[][] results) {
        // 1. 승패 관계 행렬: win[i][j] = i번 선수가 j번 선수를 이김 (0-indexed)
        boolean[][] win = new boolean[n][n];
        for (int[] r : results) {
            win[r[0] - 1][r[1] - 1] = true;
        }

        // 2. 플로이드-워셜로 승패 관계의 전이적 폐쇄 계산
        //    i가 k를 이기고 k가 j를 이기면 i는 j를 이긴다
        for (int k = 0; k < n; k++) {
            for (int i = 0; i < n; i++) {
                if (win[i][k]) {
                    for (int j = 0; j < n; j++) {
                        if (win[k][j]) {
                            win[i][j] = true;
                        }
                    }
                }
            }
        }

        // 3. 다른 모든 선수와 승패가 확정된 선수 카운트
        int answer = 0;
        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = 0; j < n; j++) {
                if (i != j && (win[i][j] || win[j][i])) {
                    count++;
                }
            }
            if (count == n - 1) {
                answer++;
            }
        }
        return answer;
    }
}
```

## 학습 노트

- 막혔던 점: 없음. 직접 경기 결과만으로는 순위를 확정할 수 없다는 점이 이 문제의 함정인데, 승패 관계의 전이성을 떠올리면 전이적 폐쇄 문제로 바로 귀결된다.
- 핵심 포인트: 순위가 확정된다는 것은 "이기든 지든 다른 모든 선수와 승패가 연결된다"는 뜻이다. 전이적 폐쇄를 구한 뒤 각 행에서 양방향 연결 개수를 세면 된다.
- 개선: 플로이드-워셜 대신 각 선수마다 BFS/DFS를 두 번(승리 방향, 패배 방향) 돌리는 방법도 있다. 복잡도는 O(n × (n + m))으로 n=100에서는 플로이드-워셜과 체감 차이가 없다. n이 훨씬 커지면 비트셋(BitSet)으로 행 단위 OR 연산을 하는 방식이 더 빠르다.

- 공간 복잡도: O(n²) — n×n 승패 행렬.

## 요약

승패 관계는 전이적이므로 직접 경기 결과만으로 순위를 매길 수 없고, 플로이드-워셜로 전이적 폐쇄를 구한 뒤 다른 모든 선수와 승패가 연결된 선수를 세면 된다. 시간 복잡도 O(n³), 공간 복잡도 O(n²)로 n ≤ 100 제한 안에서 충분히 여유가 있다.
