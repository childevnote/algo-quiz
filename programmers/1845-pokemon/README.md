## 문제 분석 및 핵심 로직

N마리 중 N/2마리를 골라 최대한 다양한 종류를 가져가는 문제. 관건은 두 가지 숫자의 관계다.

1. 전체에서 고를 수 있는 마릿수: `N / 2`
2. 존재하는 서로 다른 종류의 수: `set(nums)`의 크기

가질 수 있는 종류의 수는 이 둘 중 작은 값을 넘을 수 없다. 모든 종류를 각각 한 마리씩 가져간다 해도 고를 수 있는 마릿수가 한계가 되고, 반대로 충분히 많이 고를 수 있어도 존재하지 않는 종류는 못 가져간다. 즉 정답은 `min(N/2, 서로 다른 종류 수)` 한 줄이다. 모든 마리를 다른 종류로 가정하면 종류 수가 마릿수를 제한하고, 중복이 심하면 마릿수가 종류 수를 제한한다.

## 개념별 심층 설명

### 초심자 방식: 각 마리마다 "이미 본 종류인가"를 리스트로 확인

익숙한 패턴은 `seen = []` 같은 리스트를 두고, 마리 번호가 이미 있으면 건너뛰고 없으면 추가하는 식이다. 동작은 맞지만 `in` 연산이 매번 리스트를 처음부터 훑어 최악 O(N²)가 된다. 종류가 200,000개나 되는 입력에서는 사실상 느리다.

### 개선 방식: 해시 집합으로 한 번에

`set`은 각 번호를 해시로 저장하므로 "이미 있는가" 확인이 평균 O(1)이다. `set(nums)` 한 줄로 중복 제거가 끝나고, 전체가 O(N)에 끝난다. 해시가 느려 보이는 입력(N=10,000, 번호 범위 1~200,000)에서도 문제없는 규모다.

### 왜 `min`인가

종류를 최대한 다양하게 가져가려면 서로 다른 번호를 마릿수만큼만 뽑으면 된다. 번호가 마릿수보다 적으면 전부 다 가져가는 것이 최선이고, 종류가 더 많으면 마릿수만큼만 가져간다. "중복된 번호끼리 몇 마리씩인가" 같은 세밀한 분포는 답에 영향을 주지 않는다.

## 최종 솔루션 코드

### Python

```python
# https://school.programmers.co.kr/learn/courses/30/lessons/1845
# 폰켓몬 — 풀이일: 2026-10-14

def solution(nums):
    pick = len(nums) // 2          # ① 고를 수 있는 마릿수
    kinds = len(set(nums))         # ② 존재하는 종류 수 (해시 집합으로 중복 제거)
    return min(pick, kinds)        # ③ 둘 중 작은 값이 가져갈 수 있는 종류의 최댓값
```

### Java

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int solution(int[] nums) {
        int pick = nums.length / 2;      // ① 고를 수 있는 마릿수
        Set<Integer> kinds = new HashSet<>();
        for (int n : nums) {
            kinds.add(n);                // ② 중복 제거 (평균 O(1))
        }
        return Math.min(pick, kinds.size());  // ③ 둘 중 작은 값
    }
}
```

## 성능 측정

- 예제 3케이스 (Python): 즉시 통과. n=100,000 무작위 케이스: 약 11.1ms, 피크 메모리 약 6.3MB (tracemalloc 기준).
- Java: n=100,000 무작위 케이스 약 26.5ms, 힙 사용 약 8.3MB.
- 시간 복잡도: O(N) — 배열 한 번 순회 + 해시 집합 삽입 평균 O(1).
- 공간 복잡도: O(K) — 서로 다른 종류 수 K만큼 집합 저장.

## 요약

- 가질 수 있는 종류의 수는 `min(선택 가능한 마릿수, 서로 다른 종류의 수)`로 귀결된다.
- 중복 제거에는 해시 집합을 사용한다. 리스트의 `in` 확인으로 같은 일을 하면 O(N²)로 느려진다.
- 입력 분포(중복의 정도)는 답에 영향을 주지 않는다. 종류 수와 마릿수 두 숫자만 보면 된다.
