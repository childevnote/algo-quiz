# 개념 정리 — 해시 집합(Hash Set)

폰켓몬(1845)을 푸는 데 필요한 개념.

## 해시 집합이란

값을 "해시"로 변환해 저장하는 자료구조. 같은 값이 다시 들어오면 해시가 겹치므로 자동으로 중복이 제거된다. 존재 여부를 확인할 때 리스트처럼 처음부터 훑지 않고 해시 테이블에서 바로 찾으므로 평균 시간 복잡도는 O(1)이다.

## 왜 중복 제거에 유리한가

리스트의 `in` 연산은 최악의 경우 저장된 원소 전체를 비교한다. 원소가 N개면 N번 확인하고, 이 확인을 N개 원소에 대해 반복하면 O(N²)가 된다. 해시 집합은 확인 한 번이 O(1)이므로 전체가 O(N)으로 끝난다.

## 일반적인 예시

```python
seen = set()
for v in [5, 3, 5, 7, 3]:
    seen.add(v)
print(seen)       # {3, 5, 7} — 순서 없이 중복만 제거됨
print(len(seen))  # 3 — 서로 다른 값의 개수
```

```java
Set<Integer> seen = new HashSet<>();
for (int v : new int[]{5, 3, 5, 7, 3}) {
    seen.add(v);
}
System.out.println(seen.size());  // 3
```

## 해시 집합의 트레이드오프

- 순서를 보장하지 않는다. 삽입 순서를 유지하려면 LinkedHashSet(Python 3.7+ dict도 가능)을 쓴다.
- 메모리 사용이 리스트보다 크다. 해시 테이블 버킷을 유지해야 하기 때문이다.
- 원소는 해시 가능해야 한다. Python에서는 리스트·딕셔너리 같은 가변 객체를 넣을 수 없다.
