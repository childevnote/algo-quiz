# 개념 정리

## 나머지 연산

`a % b`는 `a`를 `b`로 나눈 나머지를 뜻한다. 나머지는 항상 나누는 수보다 작다. 예를 들어 `17 % 5`는 2이다. `a % b == 0`이면 `a`는 `b`로 나누어떨어진다고 말하고, 이때 `b`는 `a`의 약수이다.

나머지가 0이 아닌 경우에도 식을 변형할 수 있다. `a % b == r`이면 `a - r`은 `b`의 배수이다. 예를 들어 `17 % 5 == 2`이므로 `17 - 2 = 15`는 5의 배수이다.

## 약수와 약수의 대칭성

어떤 수 `m`의 약수 `d`에 대해 `m / d`도 `m`의 약수이다. 예를 들어 36의 약수 4에 대응하는 짝은 9이다. 두 약수 중 작은 쪽은 항상 `sqrt(m)` 이하이다. `d`와 `m / d`가 둘 다 `sqrt(m)`보다 크면 곱이 `m`보다 커져서 모순이 되기 때문이다.

따라서 어떤 수가 소수인지 판정하거나 가장 작은 약수를 찾을 때 `sqrt(m)`까지만 검사하면 충분하다. 36의 경우 `sqrt(36) = 6`까지만 검사하면 되고, 실제로 가장 작은 약수 2는 6 이하에서 바로 발견된다. 37의 경우 6까지 검사해도 약수가 없으므로 37은 소수임이 확정된다.

## 제곱근 경계 검사 시 주의점

`x * x <= m` 형태로 비교하면 부동소수점 오차를 피할 수 있다. `math.sqrt`를 쓰는 방식은 `sqrt`의 부동소수점 오차 때문에 경계값에서 약수를 놓칠 수 있다. 정수 곱셈으로 비교하면 이런 문제가 없다. 다만 `x * x`가 정수 범위를 넘을 수 있는 언어에서는 곱하기 전에 더 큰 정수 타입으로 변환하는 것이 안전하다.
