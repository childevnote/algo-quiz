# 타겟 넘버

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/43165
- 레벨: Lv.2
- 카테고리: DFS/BFS
- 풀이 날짜: 2026-10-29 (18:00 자동 풀이)

## 문제 핵심 요약

순서를 바꾸지 않고 주어진 숫자들 앞에 각각 `+` 또는 `-` 부호를 붙여, 최종 합이 타겟 넘버와 같아지는 경우의 수를 구하는 문제다.

- 제한사항: 숫자의 개수 2개 이상 20개 이하, 각 숫자는 1 이상 50 이하, 타겟 넘버는 1 이상 1000 이하
- 입출력 예: `[1, 1, 1, 1, 1], 3 → 5` / `[4, 1, 2, 1], 4 → 2`

## 문제 분석 및 핵심 로직

각 숫자는 더하거나 빼는 두 가지 선택지만 가지므로, 전체 경우의 수는 최대 2^20(약 100만)이다. 모든 경우를 끝까지 탐색해도 제한 안에 충분히 들어가므로, 별도의 가지치기나 동적 프로그래밍 없이 완전탐색으로 풀 수 있다.

핵심은 "숫자를 사용하는 순서는 고정되어 있고, 각 단계마다 두 갈래로 나뉜다"는 점이다. 현재까지의 합과 몇 번째 숫자까지 처리했는지만으로 상태를 표현할 수 있어, 재귀 함수가 자연스럽게 이진 트리 탐색이 된다. 모든 숫자를 다 쓴 뒤 합이 타겟과 같은지를 확인해 1 또는 0을 반환하고, 상위 호출에서 두 갈래의 결과를 합산한다.

## 개념별 심층 설명

### 깊이 우선 탐색(DFS) — 이진 선택 트리

이 문제는 각 단계마다 선택지가 정확히 두 개(더하기, 빼기)인 이진 트리다. DFS는 한 갈래를 끝까지 파고든 뒤 되돌아와 다른 갈래를 탐색하는 방식이다.

초심자 방식은 보통 결과를 전역 변수에 누적하거나, 리스트에 모든 부호 조합을 만들어 저장한 뒤 합을 계산한다. 조합을 저장하는 방식은 2^n개의 리스트를 메모리에 들고 있어야 해서 공간이 크게 늘어난다. 개선 방식은 합을 인자로 넘기면서 재귀만으로 탐색하는 것으로, 중간 결과를 저장하지 않으므로 재귀 깊이만큼의 스택 공간만 사용한다. 재귀 호출이 반환될 때 합산이 이루어지기 때문에 별도의 누적 변수가 필요 없다.

### 재귀 종료 조건과 합산 구조

재귀의 종료 조건은 "모든 숫자를 다 사용했는가"이다. 이때 합이 타겟과 같으면 경우의 수 1, 다르면 0을 반환한다. 각 호출은 `더하는 경우의 수 + 빼는 경우의 수`를 반환하므로, 최종적으로 루트 호출이 전체 경우의 수를 돌려준다. 이 구조에서는 중간 단계에서 타겟을 초과했다고 가지치기를 할 수 없는데, 뒤에 오는 숫자를 빼면 합이 다시 줄어들 수 있기 때문이다. 가지치기가 불가능하다는 점이 이 문제의 탐색을 단순 완전탐색으로 만드는 이유다.

### 대안: 메모이제이션

`(인덱스, 현재 합)`을 키로 하는 메모이제이션을 쓰면 중복 상태를 한 번만 계산할 수 있다. 다만 숫자 개수가 최대 20개라 완전탐색만으로 충분하고, 합이 음수가 될 수 있어 딕셔너리 키 관리가 추가된다. 이 풀이에서는 단순함을 우선해 메모이제이션 없이 구현했다.

## 최종 솔루션 코드

### Python

```python
def solution(numbers, target):
    # 1. 재귀 DFS: 각 숫자를 더하거나 빼는 두 갈래로 탐색
    def dfs(idx, total):
        # 2. 모든 숫자를 사용했으면 합이 target인지 확인
        if idx == len(numbers):
            return 1 if total == target else 0
        # 3. 현재 숫자를 더하는 경우와 빼는 경우를 합산
        return dfs(idx + 1, total + numbers[idx]) + dfs(idx + 1, total - numbers[idx])

    return dfs(0, 0)
```

### Java

```java
class Solution {
    public int solution(int[] numbers, int target) {
        return dfs(numbers, target, 0, 0);
    }

    // 1. 재귀 DFS: 각 숫자를 더하거나 빼는 두 갈래로 탐색
    private int dfs(int[] numbers, int target, int idx, int total) {
        // 2. 모든 숫자를 사용했으면 합이 target인지 확인
        if (idx == numbers.length) {
            return total == target ? 1 : 0;
        }
        // 3. 현재 숫자를 더하는 경우와 빼는 경우를 합산
        return dfs(numbers, target, idx + 1, total + numbers[idx])
             + dfs(numbers, target, idx + 1, total - numbers[idx]);
    }
}
```

## 요약

순서를 고정하고 각 숫자에 부호를 붙이는 모든 경우를 DFS로 탐색한다. n ≤ 20이라 완전탐색이 충분하고, 반환값 합산 방식 덕분에 별도의 누적 변수나 조합 저장 없이 O(n) 공간으로 풀 수 있다.
