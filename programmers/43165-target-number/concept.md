# 개념 정리: 깊이 우선 탐색(DFS)과 재귀 합산

## 깊이 우선 탐색(DFS)이란

DFS는 가능한 선택을 한 방향으로 끝까지 탐색한 뒤, 되돌아와 다른 선택을 시도하는 탐색 방식이다. 스택(명시적 스택 또는 재귀 호출 스택)을 이용해 "한 갈래를 끝까지"라는 순서를 구현한다.

각 단계에서 선택지가 k개이고 단계가 n개라면, 탐색 트리의 잎은 최대 k^n개가 된다. DFS의 공간 복잡도는 트리의 깊이 수준인 O(n)이다. 너비 우선 탐색(BFS)이 같은 깊이의 노드를 모두 들고 있어야 하는 것과 달리, DFS는 현재 경로만 유지하면 되기 때문이다.

### 일반 예시: 부분집합 개수 세기

```python
def count_subsets(n):
    # n개의 원소에서 만들 수 있는 부분집합의 개수 (각 원소: 포함/미포함)
    def dfs(idx):
        if idx == n:
            return 1
        return dfs(idx + 1) + dfs(idx + 1)
    return dfs(0)
```

이 코드에서 `dfs(idx + 1) + dfs(idx + 1)`은 "원소를 포함하는 경우의 수 + 포함하지 않는 경우의 수"를 의미한다. 반환값을 합산하는 구조라 전역 카운터가 필요 없다.

## 재귀 함수의 세 요소

1. **상태**: 재귀 호출마다 달라지는 값. 보통 "지금 몇 단계까지 왔는가"(인덱스)와 "지금까지 누적된 값"이다.
2. **종료 조건**: 더 이상 분기할 단계가 없을 때의 처리. 탐색의 잎에 도달하면 조건에 따라 1 또는 0 같은 기본값을 반환한다.
3. **분기와 합산**: 현재 단계의 각 선택마다 재귀 호출을 하고, 그 결과들을 합하거나 비교해 상위 호출에 넘긴다.

## 가지치기가 불가능한 경우

가지치기는 "이 갈래는 답이 될 수 없다"고 확신할 때만 안전하다. 누적값이 단조롭게 증가하거나 감소하는 문제에서는 중간값으로 가지치기가 가능하지만, 뒤의 선택에 따라 값이 다시 오르내릴 수 있는 문제에서는 중간값만으로는 갈래를 버릴 수 없다. 이런 경우 완전탐색이 정당한 선택이며, 입력 크기가 작으면 충분히 빠르다.

## 메모이제이션과의 관계

재귀 호출의 상태가 겹치는 경우가 많으면, `(인덱스, 누적값)` 같은 상태 키로 결과를 캐싱해 중복 계산을 줄일 수 있다. 이를 메모이제이션이라 하며, 본질적으로는 DFS + 캐시다. 상태 공간이 작을 때 효과적이고, 상태 공간이 탐색 트리 자체와 비슷하게 클 때는 효과가 제한적이다.
