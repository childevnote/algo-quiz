# 회전 정규화와 최댓값 집계

## 1. 회전 정규화

- 방향이 자유로운 직사각형을 다룰 때, 각 도형을 같은 기준으로 정렬하면 경우의 수를 따지지 않아도 된다
- 관례: 긴 쪽을 가로, 짧은 쪽을 세로로 통일
- Python: `w, h = max(w, h), min(w, h)`
- Java: `Math.max` / `Math.min` 조합

## 2. 최댓값 집계 패턴

- "모든 원소를 포함하는 최소 범위"는 각 차원의 최댓값을 구하면 된다
- 한 번의 순회로 끝나며 추가 배열이 필요 없다
- Python: `max_w = max(max_w, w)` 누적
- Java: `maxW = Math.max(maxW, w)` 누적

## 3. 시간복잡도

- n개의 원소를 한 번 훑으며 상수 개의 값만 유지하면 O(n) 시간, O(1) 공간
- 정렬이 필요 없는 집계 문제는 정렬(O(n log n))을 쓰지 않는다
