# 올림 나눗셈과 누적 기준값을 이용한 단일 패스 그룹화

## 1. 올림 나눗셈 (Ceiling Division)

- a를 b로 나눈 나머지가 있으면 몫에 1을 더한 값이 필요할 때 쓰는 기법
- 부동소수점으로 나누고 올림하면 오차 우려가 있어, 정수 연산으로 처리하는 것이 안전하다
- 정수 올림 공식: `(a + b - 1) // b` (a, b는 양의 정수)
- Python 일반 예시: 작업량 100을 하루 7씩 처리하면 `math.ceil(100 / 7)` → 15일, 정수식으로는 `(100 + 7 - 1) // 7` → 15
- Java 일반 예시: `int days = (total + perDay - 1) / perDay;` — 정수 나눗셈은 자동으로 내림이므로 `+ perDay - 1` 보정이 올림 역할을 한다

## 2. 순서 보장 (FIFO 차단)

- "앞 작업이 나가기 전에는 뒤 작업이 나갈 수 없다"는 규칙을 코드로 표현하는 개념
- 큐와 같은 구조: 먼저 들어온 것이 먼저 처리되지 않으면 뒤의 것은 대기한다
- 일반 예시: 공장 컨베이어 벨트의 검사 공정 — 앞 공정이 끝나기 전에는 뒤의 제품이 다음 단계로 넘어갈 수 없으므로, 뒤 제품은 먼저 준비가 끝나도 대기 라인에 머문다
- 이 규칙이 있으면 뒤쪽 요소는 앞쪽 요소의 상태(완료 시점)를 기준으로만 행동이 정해진다

## 3. 누적 기준값으로 단일 패스 그룹화

- 배열을 앞에서 뒤로 한 번 훑으면서 "지금까지의 누적 기준값"을 유지하고, 각 원소가 그 기준을 넘는 순간 그룹 경계를 나누는 패턴
- 일반 예시 (일일 최고가 경신일 세기): 주가 배열을 순회하며 지금까지의 최고가를 유지하고, 최고가를 경신하는 날을 센다 — 경신 여부는 최고가라는 단일 값과의 비교만으로 판단되며, 전체 순회는 한 번이면 충분하다
- Python 일반 예시:

```python
def count_records(values):
    best = values[0]
    count = 1
    for v in values[1:]:
        if v > best:      # 누적 기준값을 넘으면
            best = v      # 기준 갱신 + 새 구간 시작
            count += 1
    return count
```

- Java 일반 예시:

```java
int best = values[0], count = 1;
for (int i = 1; i < values.length; i++) {
    if (values[i] > best) {
        best = values[i];
        count++;
    }
}
```

- 핵심: 그룹 경계를 판단하는 데 필요한 정보가 누적 기준값 하나로 압축되므로, 앞쪽 구간을 다시 훑을 필요가 없고 시간복잡도가 O(n)으로 유지된다
