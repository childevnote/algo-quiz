## 문제 핵심 요약

삼각형 모양으로 놓인 숫자들의 꼭대기에서 바닥까지, 아래 칸으로 대각선 방향(왼쪽 아래 또는 오른쪽 아래)으로만 이동하면서 거쳐간 숫자의 합이 가장 커지는 경로를 찾는 문제다. 삼각형 정보가 담긴 2차원 배열이 주어지고, 그 경로상의 최대합을 반환한다.

- 제한사항: 삼각형의 높이는 1 이상 500 이하, 삼각형을 이루는 숫자는 0 이상 9,999 이하의 정수
- 입출력 예: `[[7], [3, 8], [8, 1, 0], [2, 7, 4, 4], [4, 5, 2, 6, 5]] → 30` (경로 7 → 3 → 8 → 7 → 5)

## 문제 분석 및 핵심 로직

꼭대기에서 출발해 매 행마다 왼쪽 아래나 오른쪽 아래 중 하나를 고르면, 높이가 500인 삼각형에서는 경로가 최대 2^499개까지 생긴다. 모든 경로를 일일이 열거하는 것은 불가능하다.

대신 아래에서 위로 올라가며 생각한다. 어떤 칸에 도달했을 때, 그 칸에서 바닥까지 얻을 수 있는 최대합은 그 칸의 값에 "바로 아래 두 칸 중 더 큰 쪽에서 출발하는 최대합"을 더한 값과 같다. 바닥 행에서는 더 내려갈 곳이 없으니 각 칸의 값 자체가 곧 최대합이다. 바닥 행부터 한 행씩 위로 올라가며 이 값을 채우면, 마지막에 꼭대기 칸에 남은 값이 전체 경로의 최대합이 된다.

이때 아래 두 칸 중 더 큰 쪽을 고르는 선택은 지역적인 탐욕이 아니라, 아래쪽의 최적값이 이미 확정된 뒤의 선택이다. 아래 행의 각 칸에는 그 칸에서 바닥까지의 최적합이 이미 들어 있으므로, 현재 칸에서 어느 쪽으로 내려가든 그 아래로는 최적의 경로가 이어진다. 그래서 두 값 중 큰 쪽을 고르는 것이 전체 최적을 보장한다.

## 개념별 심층 설명

### 아래에서 위로 채우는 동적 프로그래밍

보통 동적 프로그래밍은 작은 부분 문제부터 풀어 큰 문제의 답을 만든다. 이 문제에서는 "어떤 칸에서 바닥까지의 최대합"이 부분 문제다. 바닥 행은 답이 자명하고(자기 자신), 그 위 행은 바닥 행의 답만으로 구할 수 있으며, 이런 식으로 꼭대기까지 올라가면 전체 답이 나온다.

초심자 방식은 위에서 아래로 내려가며 경로를 탐색하는 것이다. 재귀로 모든 경로를 따라가면 높이가 h일 때 2^(h-1)개의 경로를 모두 봐야 하고, 높이가 500이면 계산이 끝나지 않는다. 메모이제이션을 붙이면 같은 칸을 여러 번 계산하지 않게 되지만, 재귀 호출이 깊어지고(500단) 별도의 테이블을 관리해야 한다. 개선 방식은 반복문으로 아래 행부터 채우는 것이다. 아래 행의 값이 전부 확정된 뒤에야 위 행을 계산할 수 있다는 의존 관계가 명확하므로, 행을 거꾸로 도는 단순한 이중 반복문으로 충분하고 재귀도, 별도의 방문 표시도 필요 없다.

### 1차원 배열로 공간 줄이기

각 행을 계산할 때는 바로 아래 행의 값만 필요하다. 그래서 삼각형 전체와 같은 크기의 2차원 테이블을 유지할 필요가 없고, 마지막 행 길이만큼의 1차원 배열 하나로 충분하다. 배열의 j번째 원소는 "현재 행의 j번째 칸에서 바닥까지의 최대합"을 의미하며, 한 행을 처리할 때마다 왼쪽에서 오른쪽으로 덮어쓰면 된다. 덮어쓰기가 안전한 이유는, j번째 칸을 계산할 때 필요한 아래 행의 j번째와 j+1번째 값이 아직 덮어쓰기 전 상태로 남아 있기 때문이다. 왼쪽부터 채우면 j+1번째 값은 아직 손대지 않은 아래 행의 값이다.

이 배열 하나만으로 공간 복잡도는 O(n)(n은 삼각형 높이)까지 줄어든다. 원본 삼각형 자체를 직접 수정하는 방법도 있지만, 입력 배열을 건드리지 않고 별도의 배열을 쓰는 쪽이 입력 재사용 시 부작용이 없다.

## 최종 솔루션 코드

### Python

```python
def solution(triangle):
    # 1. 마지막 행을 누적 최대합 배열로 복사해 시작점으로 삼는다
    dp = triangle[-1][:]
    # 2. 아래 행부터 위로 올라가며 각 칸에 도달 가능한 최대합을 누적한다
    for i in range(len(triangle) - 2, -1, -1):
        for j in range(len(triangle[i])):
            # 3. 바로 아래 두 칸 중 더 큰 쪽과 현재 값을 더한다
            dp[j] = triangle[i][j] + max(dp[j], dp[j + 1])
    # 4. 꼭대기에 남은 값이 전체 경로의 최대합이다
    return dp[0]
```

### Java

```java
import java.util.Arrays;

class Solution {
    public int solution(int[][] triangle) {
        // 1. 마지막 행을 누적 최대합 배열로 복사해 시작점으로 삼는다
        int[] dp = Arrays.copyOf(triangle[triangle.length - 1], triangle[triangle.length - 1].length);
        // 2. 아래 행부터 위로 올라가며 각 칸에 도달 가능한 최대합을 누적한다
        for (int i = triangle.length - 2; i >= 0; i--) {
            for (int j = 0; j < triangle[i].length; j++) {
                // 3. 바로 아래 두 칸 중 더 큰 쪽과 현재 값을 더한다
                dp[j] = triangle[i][j] + Math.max(dp[j], dp[j + 1]);
            }
        }
        // 4. 꼭대기에 남은 값이 전체 경로의 최대합이다
        return dp[0];
    }
}
```

## 학습 노트

- 막혔던 점: 18:00 자동 풀이로 진행되어 별도의 막힘 없이 풀이했다. 엣지 케이스(높이 1, 전부 0, 한쪽으로만 큰 값)는 별도 검증으로 통과했다.
- 핵심 포인트: 바닥 행부터 위로 올라가며 "이 칸에서 바닥까지의 최대합"을 채운다. 각 칸은 바로 아래 두 칸 중 더 큰 쪽을 선택하고, 그 선택은 아래쪽 최적값이 이미 확정된 뒤의 것이므로 전체 최적을 보장한다.
- 개선: 2차원 DP 테이블 대신 마지막 행 길이만큼의 1차원 배열 하나로 공간을 줄였다. 각 행을 계산할 때 바로 아래 행만 필요하고, 왼쪽부터 덮어쓰면 아직 쓰지 않은 오른쪽 값이 보존되기 때문이다.

## 요약

바닥 행에서 시작해 위로 올라가며 각 칸에 "이 칸에서 바닥까지의 최대합"을 누적한다. 각 칸은 바로 아래 두 칸 중 더 큰 쪽과 자신의 값을 더하고, 꼭대기에 남은 값이 곧 답이다. 1차원 배열 하나로 공간을 줄인 O(n²) 시간, O(n) 공간의 풀이이다.
