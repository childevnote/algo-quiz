# 개념 정리

## 1. 원형 거리

양끝이 이어진 구조에서는 두 지점 사이의 거리가 한 방향으로 잰 거리가 아니라, 양쪽 방향 중 짧은 쪽이다.

예를 들어 0부터 11까지의 숫자가 원형으로 배치된 시계를 생각해 보자. 0에서 11까지 시계 방향으로는 11칸이지만, 반대 방향으로는 1칸이다. 원형 거리는 1이다.

일반적으로 크기가 `m`인 원형 구조에서 두 지점의 한 방향 거리가 `d`라면, 반대 방향 거리는 `m - d`이고 원형 거리는 `min(d, m - d)`이다. 이 값은 항상 `m / 2`를 넘지 않는다.

```python
def circular_distance(a, b, m):
    d = abs(a - b)
    return min(d, m - d)

print(circular_distance(0, 11, 12))  # 1
print(circular_distance(0, 25, 26))  # 1
```

원형 거리를 쓸 때는 "끝에서 반대쪽 끝으로 넘어간다"는 점을 잊지 말아야 한다. 선형 거리로 계산하면 끝 근처 지점 사이의 거리를 크게 과대평가하게 된다.

## 2. 탐욕적 선택과 분리

여러 종류의 비용이 서로 영향을 주지 않을 때는 각 비용을 따로 최소화한 뒤 합쳐도 전체 최적값이 된다. 이를 비용 분리라고 부를 수 있다.

예를 들어 어떤 작업을 할 때 "각 항목을 바꾸는 비용"과 "항목 사이를 이동하는 비용"이 서로 독립이라면, 바꾸는 비용은 항목마다 최선의 방법을 택하고, 이동 비용은 방문 순서만으로 따로 최적화하면 된다. 한쪽의 선택이 다른 쪽의 비용을 바꾸지 않는다는 점이 전제이다.

반대로 이동 순서가 바꾸는 비용에 영향을 준다면(예: 이동하면서 상태가 변한다) 분리할 수 없고, 두 비용을 함께 고려해야 한다.

## 3. 건너뛸 구간이 있는 순회

배열을 한 방향으로 순회하다가 처리할 필요가 없는 구간을 만나면, 그 구간을 통과하는 대신 방향을 바꿔 반대쪽에서 접근하는 편이 짧을 수 있다.

일반적인 패턴은 다음과 같다. 순회 방향이 원형으로 이어져 있고, 건너뛸 구간이 연속되어 있을 때:

- 구간 앞까지 갔다가 되돌아와 반대쪽에서 진입하는 경로
- 처음부터 반대 방향으로 돌아 반대쪽에서 진입하는 경로

두 경로의 비용은 각각 "이미 이동한 거리의 두 배 + 남은 거리" 형태가 된다. 되돌아가는 비용이 들기 때문에, 되돌아가는 지점은 건너뛸 구간 바로 앞이 최적이다. 더 일찍 되돌아가면 남은 구간이 길어지고, 더 늦게 되돌아가면 되돌아가는 거리가 길어지기 때문이다.

```python
# 길이가 n인 원형 배열에서, 위치 i 뒤에 건너뛸 구간이 있고
# 다음으로 처리할 위치가 nxt일 때의 두 우회 경로 비용
cost_backtrack = i * 2 + (n - nxt)
cost_go_other_way = (n - nxt) * 2 + i
```

이 패턴은 "모든 필요한 위치를 방문하되, 불필요한 구간은 지나지 않는다"는 형태의 순회 문제에 공통으로 적용된다.
