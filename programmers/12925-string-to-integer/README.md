# 문자열을 정수로 바꾸기

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12925
- 레벨: Lv.1
- 카테고리: 연습문제

## 문제 핵심 요약

부호와 숫자로만 이루어진 문자열 `s`를 정수로 변환해 반환한다. 맨앞에는 `+` 또는 `-` 부호가 올 수 있다.

- 제한사항: `s`의 길이는 1 이상 5 이하, `s`는 부호와 숫자로만 구성, `s`는 "0"으로 시작하지 않음
- 입출력 예: `"1234" → 1234`, `"-1234" → -1234`

## 문제 분석 및 핵심 로직

문자열 `"1234"`를 숫자 `1234`로 바꾸는 일은, 십진법 자리값의 뜻을 그대로 풀어쓰는 일이다. `"1234"`는 `1×1000 + 2×100 + 3×10 + 4`이며, 왼쪽 자리부터 한 자리씩 읽으면서 `result = result × 10 + 자릿수`를 반복하면 같은 값을 얻을 수 있다. `1`에서 시작해 `12`, `123`, `1234`로 커지는 과정이 바로 이 식이다.

문자 한 개를 숫자로 바꾸는 방법은 문자 코드의 차이를 이용한다. `'0'`부터 `'9'`까지의 문자는 코드값이 연속으로 나열되어 있어, `'3' - '0'`은 숫자 `3`이 된다. 부호는 맨앞 한 글자만 따로 확인한다. `'-'`이면 음수, `'+'`이거나 없으면 양수이다. 부호를 확인한 뒤에는 숫자 부분만 누적하고, 마지막에 음수이면 부호를 뒤집는다.

## 개념별 심층 설명

### 초심자 방식: 내장 변환 함수에 맡기기

Python의 `int(s)`나 Java의 `Integer.parseInt(s)`를 쓰면 한 줄로 끝난다. 간결하고 검증된 동작이라 실무에서는 이 방식이 맞다. 다만 이 문제의 학습 목적은 변환이 내부에서 어떻게 일어나는지를 아는 데 있다. 내장 함수는 부호 처리와 자리값 누적을 내부에 숨기고 있어, 그 원리를 모른 채 쓰게 된다.

### 개선 방식: 자리값 누적 직접 구현하기

십진수 문자열을 왼쪽부터 읽으며 `result = result * 10 + digit`을 반복한다. 이 식은 새 자릿수가 들어올 때마다 기존 숫자를 한 자리 왼쪽으로 밀어내는(10을 곱하는) 동작이다. `"1234"`의 경우 `0 → 1 → 12 → 123 → 1234` 순으로 값이 커진다.

문자에서 숫자를 얻는 핵심은 `'0'`과의 차이이다. `'0'`의 코드값이 48, `'1'`이 49, `'9'`가 57이므로, 어떤 숫자 문자에서 `'0'`을 빼면 그 문자가 나타내는 숫자 자체가 된다. `ord('3') - ord('0')`은 `51 - 48 = 3`이다. Python에서는 `ord()`를, Java에서는 문자끼리의 뺄셈(`s.charAt(i) - '0'`)을 쓴다.

부호 처리는 누적과 분리한다. 맨앞 글자가 `'-'`인지 먼저 확인해두고 숫자 부분만 양수로 누적한 뒤, 마지막에 음수이면 `-result`로 뒤집는다. 부호를 누적 과정에 섞으면 매 자리마다 부호를 확인해야 하므로, 확인을 한 번으로 줄이는 편이 깔끔하다.

## 최종 솔루션 코드

### Python

```python
def solution(s):
    # 1. 맨앞 부호를 확인한다. '-'이면 음수, '+'이거나 없으면 양수이다.
    # 2. 숫자 자릿수를 왼쪽부터 한 자리씩 누적한다: result = result * 10 + digit.
    #    '0' 문자의 코드값을 빼면 문자 '3'은 숫자 3이 된다.
    # 3. 음수이면 부호를 뒤집어 반환한다.
    negative = s[0] == '-'
    start = 1 if s[0] in '+-' else 0
    result = 0
    for i in range(start, len(s)):
        result = result * 10 + (ord(s[i]) - ord('0'))
    return -result if negative else result
```

### Java

```java
class Solution {
    public int solution(String s) {
        // 1. 맨앞 부호를 확인한다. '-'이면 음수, '+'이거나 없으면 양수이다.
        // 2. 숫자 자릿수를 왼쪽부터 한 자리씩 누적한다: result = result * 10 + digit.
        //    '0' 문자의 코드값을 빼면 문자 '3'은 숫자 3이 된다.
        // 3. 음수이면 부호를 뒤집어 반환한다.
        boolean negative = s.charAt(0) == '-';
        int start = (s.charAt(0) == '+' || s.charAt(0) == '-') ? 1 : 0;
        int result = 0;
        for (int i = start; i < s.length(); i++) {
            result = result * 10 + (s.charAt(i) - '0');
        }
        return negative ? -result : result;
    }
}
```

Java에서 `char`끼리 빼면 `int`가 되므로 별도 변환이 필요 없다. 입력 길이가 최대 5라 결과는 최대 99999로 `int` 범위를 넘지 않는다.

## 성능 측정

로컬 실측 결과이다. 입력 길이가 최대 5로 고정되어 있어 스케일 측정은 동일 호출 100,000회 반복으로 대신했다.

| 케이스 | Python | Java |
| --- | --- | --- |
| 예제 `"1234"` → 1234 | 1.79 µs | 2.07 µs |
| `"-1234"` 100,000회 반복 (합계) | 59.91 ms | 13.79 ms |
| `"-1234"` 1회당 | 0.60 µs | 0.14 µs |
| 내장 변환 `int()` / `parseInt` 비교용, 100,000회 | 16.21 ms | — |

- Python 피크 메모리: 104 bytes (tracemalloc 실측, 1회 실행)
- 시간복잡도: O(n) — 문자열 길이 n(최대 5)에 비례해 한 번씩 순회
- 공간복잡도: O(1) — 변수 몇 개만 사용

내장 `int()`가 직접 구현보다 약 3.7배 빠른데, 이는 내장 함수가 C로 구현되어 있기 때문이다. 알고리즘 자체는 동일하며, 입력 길이가 최대 5라 실제 차이는 무시할 수준이다.

## 요약

- 핵심 아이디어: `result = result * 10 + digit`으로 왼쪽부터 자리값을 누적한다.
- 문자에서 숫자는 `'0'`과의 차이로 얻는다.
- 부호는 맨앞 한 글자만 확인하고 누적과 분리해 처리한다.
- 시간복잡도는 O(n)(n ≤ 5), 공간복잡도는 O(1)이다.
