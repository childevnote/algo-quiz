# 의상 (42578)

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42578
- 레벨: Lv.2 / 카테고리: 해시

## 문제 핵심 요약

`[의상 이름, 의상 종류]` 형태의 2차원 배열이 주어진다. 종류별로 최대 1개의 의상만 착용할 수 있고, 하루에 최소 1개는 입어야 한다. 가능한 서로 다른 착용 조합의 총수를 구하는 문제다.

## 문제 분석 및 핵심 로직

종류별로 어떤 의상을 고를지는 서로 독립이다. 예를 들어 모자 2개, 안경 1개가 있다면 모자 선택(2가지 또는 선택 안 함)과 안경 선택(1가지 또는 선택 안 함)은 서로 영향을 주지 않는다. 따라서 각 종류의 선택지 수를 곱하면 전체 조합이 나온다. 단, "모든 종류에서 선택 안 함" 1가지 경우는 하루 최소 1개를 입는다는 조건에 어긋나므로 마지막에 빼준다.

종류별 개수를 세는 데에는 해시 맵이 제격이다. 종류 이름이 문자열이므로 이를 키로 삼아 개수를 집계하면 한 번의 순회로 끝난다.

## 개념별 심층 설명

### 초심자 방식: 모든 조합을 직접 열거하기

재귀나 중첩 반복문으로 "모자는 A/B/안 씀, 안경은 C/안 씀, ..." 식의 모든 경우를 나열하면 종류 수와 의상 수가 늘어날수록 경우의 수가 기하급수적으로 불어난다. 종류가 k개, 각 종류에 n개씩 있다면 (n+1)^k가지다. 의상 수가 30개까지 가능하므로 이 방식은 금방 감당하기 어려워진다.

### 개선 방식: 곱의 법칙으로 경우의 수 계산하기

조합을 하나하나 만들 필요가 없다. 각 종류의 선택지가 독립이라는 점만 이용하면 된다.

1. 종류별 의상 개수를 센다. (예: 모자 2개, 안경 1개)
2. 각 종류마다 "n개 중 하나 고르기 + 고르지 않기" = n+1가지 선택지가 있다.
3. 종류가 독립이므로 전체 경우의 수는 (n1+1) × (n2+1) × ... 이다.
4. 여기서 "전부 고르지 않기" 1가지를 뺀다.

곱의 법칙은 "독립적인 선택들의 경우의 수는 곱한다"는 조합론의 기본 원리다. 주사위 두 개를 던질 때 나올 수 있는 눈의 조합이 6×6=36가지인 것과 같은 이치다.

### 동작 원리

Python의 `collections.Counter`나 Java의 `HashMap`으로 종류별 개수를 집계한 뒤, `(개수 + 1)`들을 차례로 곱하고 1을 뺀다. 집계는 의상 수 n에 대해 O(n), 곱셈은 종류 수에 대해 O(k)다.

## 최종 솔루션 코드

### Python

```python
from collections import Counter

def solution(clothes):
    # 1. 종류별 의상 개수를 센다
    counts = Counter(kind for _, kind in clothes)
    # 2. 종류마다 (개수 + 1)가지 선택지(해당 종류를 안 입는 경우 포함)를 곱하고,
    #    모든 종류를 안 입는 1가지 경우를 뺀다
    answer = 1
    for c in counts.values():
        answer *= (c + 1)
    return answer - 1
```

### Java

```java
import java.util.*;

class Solution {
    public int solution(String[][] clothes) {
        // 1. 종류별 의상 개수를 센다
        Map<String, Integer> counts = new HashMap<>();
        for (String[] c : clothes) {
            counts.put(c[1], counts.getOrDefault(c[1], 0) + 1);
        }
        // 2. 종류마다 (개수 + 1)가지 선택지(해당 종류를 안 입는 경우 포함)를 곱하고,
        //    모든 종류를 안 입는 1가지 경우를 뺀다
        int answer = 1;
        for (int c : counts.values()) {
            answer *= (c + 1);
        }
        return answer - 1;
    }
}
```

## 성능 측정

- 예제 케이스: Python 약 2.0µs/회, 모두 정답
- 스케일 테스트 (n=100,000, 종류 50개): Python 69.0ms / Java 41.2ms
- 시간 복잡도: O(n) — 의상 수에 대한 한 번의 순회
- 공간 복잡도: O(k) — 종류 수만큼의 해시 맵
- 참고: 제한상 의상은 최대 30개이므로 int 범위 내에서 오버플로우가 발생하지 않는다 (최대 2^30 − 1).

## 학습 노트

핵심은 "조합을 만들지 말고 경우의 수만 센다"는 발상의 전환이다. 각 종류의 선택이 독립이라는 구조를 파악하면 곱의 법칙 한 줄로 끝난다. 해시 맵은 종류별 집계를 O(n)에 처리하는 도구로 쓰였고, 문제의 본질은 조합론에 있다.

## 요약

종류별 개수를 해시 맵으로 집계하고, 각 종류의 선택지 (개수+1)을 곱한 뒤 전부 안 입는 경우 1을 뺀다. 시간 복잡도 O(n)의 풀이.
