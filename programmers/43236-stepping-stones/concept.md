# 개념 정리: 징검다리 문제를 푸는 데 필요한 개념

## 1. 이분탐색 (Binary Search)

이분탐색은 정렬된 범위에서 원하는 값을 절반씩 좁혀 가며 찾는 방법이다. 중간값을 보고 원하는 값이 왼쪽 절반에 있는지 오른쪽 절반에 있는지 판단해, 매번 탐색 범위를 절반으로 줄인다. 범위가 n이면 log n번 만에 답을 찾는다.

일반적인 예시: 1부터 100까지 숫자 중 하나를 맞히는 게임에서, "50보다 큰가?"라고 물어 답에 따라 51~100 또는 1~49로 범위를 좁히는 방식이다. 매번 절반을 버리므로 최대 7번의 질문으로 답을 찾을 수 있다.

```python
# 정렬된 배열에서 target 찾기
def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

## 2. 정답에 대한 이분탐색 (매개변수 탐색)

최적값을 직접 구하기 어려울 때, "답이 m 이상인가" 같은 yes/no 판정 문제로 바꾸어 이분탐색을 적용하는 기법이다. 판정 결과가 단조성을 가져야 한다. 즉 m이 가능하면 m보다 작은 값도 가능하고, m이 불가능하면 m보다 큰 값도 불가능해야 한다. 이 경계가 바로 구하려는 최적값이다.

일반적인 예시: n개의 나무를 잘라 길이가 m 이상인 조각을 k개 이상 얻을 수 있는가를 판정하는 문제이다. m이 작을수록 조각을 얻기 쉬우므로 판정 결과는 단조적이다. 가능한 가장 큰 m을 이분탐색으로 찾으면 답이 된다. 여기서 m의 범위는 1부터 가장 긴 나무의 길이까지이다.

```python
# 길이가 m 이상인 조각을 k개 만들 수 있는가
def can_make(lengths, m, k):
    count = 0
    for length in lengths:
        count += length // m
    return count >= k

# 가능한 가장 큰 m을 이분탐색으로 찾기
def max_length(lengths, k):
    lo, hi = 1, max(lengths)
    answer = 0
    while lo <= hi:
        mid = (lo + hi) // 2
        if can_make(lengths, mid, k):
            answer = mid
            lo = mid + 1
        else:
            hi = mid - 1
    return answer
```

이 기법이 성립하려면 판정 함수가 단조적이어야 하고, 판정 자체가 효율적으로 계산 가능해야 한다. 판정이 O(n)이면 전체 시간은 O(n log 범위)가 된다.

## 3. 탐욕법 (Greedy)

탐욕법은 매 단계에서 당장 가장 좋아 보이는 선택을 하는 방법이다. 그 선택이 전체 최적해로 이어진다는 것이 증명될 때만 올바른 답을 낸다. "지금 이 선택을 하지 않으면 나중에 손해 본다"는 교환 논증으로 정당화되는 경우가 많다.

일반적인 예시: 회의실 배정 문제에서, 끝나는 시간이 가장 이른 회의부터 배정하면 가장 많은 회의를 배정할 수 있다. 끝나는 시간이 이른 회의를 건너뛰고 늦게 끝나는 회의를 먼저 배정하면, 그만큼 뒤쪽 회의가 들어갈 자리가 줄어들기 때문이다.

```python
# 끝나는 시간이 가장 이른 회의부터 배정
def max_meetings(meetings):
    meetings.sort(key=lambda x: x[1])  # 종료 시간 순 정렬
    count = 0
    end = 0
    for start, finish in meetings:
        if start >= end:
            count += 1
            end = finish
    return count
```

탐욕법은 모든 문제에 통하지 않는다. 매 단계의 선택이 이후 선택에 어떤 영향을 미치는지 따져 보고, "지금 선택을 나중 선택으로 바꿔도 손해가 없다"는 점을 확인해야 한다. 그렇지 않으면 동적 프로그래밍 같은 다른 방법을 써야 한다.

## 4. 단조성 (Monotonicity)

단조성은 어떤 조건이 한 방향으로만 변하는 성질이다. 단조 증가 함수는 입력이 커질수록 출력이 커지거나 그대로이고, 단조 감소 함수는 입력이 커질수록 출력이 작아지거나 그대로이다. 단조성이 있으면 경계를 이분탐색으로 찾을 수 있다.

일반적인 예시: 물의 온도를 높이면 얼음은 녹는 쪽으로만 변한다. 온도가 올라갈수록 "얼음이 남아 있는가"라는 질문의 답은 참에서 거짓으로 한 번만 바뀐다. 이렇게 답이 한 번만 바뀌는 지점이 있으면, 그 지점을 이분탐색으로 찾을 수 있다.

판정 문제에서 단조성이 깨지면 이분탐색을 쓸 수 없다. 예를 들어 "m이 가능하면 m+1도 가능하다"는 보장이 없으면, 중간값을 보고 어느 쪽을 버릴지 판단할 수 없기 때문이다. 그래서 정답에 대한 이분탐색을 적용하기 전에는 항상 단조성을 먼저 확인한다.
