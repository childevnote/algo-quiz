## 문제 분석 및 핵심 로직

n개의 섬 사이에 다리를 건설하는 비용이 주어질 때, 모든 섬이 서로 통행 가능하도록 만드는 최소 비용을 구하는 문제다. 다리를 여러 번 건너 도달할 수만 있으면 통행 가능하므로, 답은 모든 섬을 연결하는 다리들의 집합 중 비용 합이 가장 작은 것, 즉 최소 신장 트리(Minimum Spanning Tree, MST)의 비용이다. 섬의 개수는 최대 100개, 간선은 최대 4,950개까지 주어진다.

핵심은 두 가지다.

1. **비용이 싼 간선부터 차례로 살펴보며, 사이클을 만들지 않는 간선만 선택한다.** 이것이 크루스칼(Kruskal) 알고리즘의 탐욕적 선택이다. 간선을 비용 오름차순으로 정렬한 뒤, 양 끝 섬이 아직 연결되지 않았을 때만 간선을 고르면 n-1개를 골랐을 때 최소 비용의 연결이 완성된다. 탐욕적 선택이 최적 해를 보장하는 이유는, 어떤 간선을 고를 때 그 간선보다 싼 간선들로만은 두 섬을 연결할 수 없기 때문이다. 더 싼 간선들만으로 두 섬이 이미 연결되어 있다면 그 간선은 사이클을 만들므로 버리고, 연결되어 있지 않다면 그 간선을 포함하지 않는 최적 해는 그 간선으로 교체해도 비용이 늘지 않는다.
2. **두 섬이 이미 연결되어 있는지를 빠르게 판정해야 한다.** 섬들을 집합으로 묶어 관리하는 서로소 집합(Disjoint Set Union, Union-Find)이 이 역할을 한다. 간선을 고를 때마다 양 끝 섬이 속한 집합이 다르면 두 집합을 합치고, 같으면 그 간선은 사이클을 만들므로 버린다. 경로 압축을 적용하면 find 연산이 거의 상수 시간에 동작한다.

### 초심자 방식 vs 개선 방식

처음 떠올리기 쉬운 방식은 모든 간선 조합을 시도해 보는 것이다. 간선이 최대 4,950개이므로 조합은 셀 수 없이 많아 제한 안에 끝나지 않는다.

간선을 비용 순으로 정렬하지 않고, 아무 순서로 간선을 고르며 사이클만 피하는 방식도 있다. 이렇게 고른 n-1개의 간선은 모든 섬을 연결하는 신장 트리가 되지만, 비용이 최소라는 보장이 없다. 비싼 간선을 먼저 골라 버리면, 나중에 싼 간선이 남아 있어도 이미 연결된 섬 사이에는 쓸 수 없기 때문이다.

크루스칼 방식은 간선을 한 번 정렬한 뒤 선형으로 스캔하면서 Union-Find로 사이클 여부만 검사한다. 정렬이 전체 비용을 지배하며, 간선 수가 E개일 때 O(E log E) 시간에 최소 비용을 확정한다.

### 동작 원리

1. 모든 간선을 비용 오름차순으로 정렬한다.
2. 각 섬을 자기 자신만을 원소로 하는 집합으로 초기화한다. 부모 배열의 각 원소가 자기 자신을 가리키게 한다.
3. 정렬된 간선을 순서대로 살펴본다. 간선의 양 끝 섬에 대해 find로 각 섬이 속한 집합의 대표를 찾는다.
4. 두 대표가 다르면 두 섬은 아직 연결되지 않은 상태이므로, 간선을 선택하고 두 집합을 합친다(한쪽 대표의 부모를 다른 쪽 대표로 설정한다). 선택한 간선의 비용을 답에 더한다.
5. 두 대표가 같으면 두 섬은 이미 다른 간선들로 연결되어 있으므로, 이 간선을 고르면 사이클이 생긴다. 건너뛴다.
6. 선택한 간선이 n-1개가 되면 최소 신장 트리가 완성된 것이므로 탐색을 멈추고 누적한 비용을 반환한다. 섬이 1개이면 선택할 간선이 없어 비용은 0이다.

## 최종 솔루션 코드

### Python

```python
def solution(n, costs):
    # 1. 간선을 비용 오름차순으로 정렬
    costs.sort(key=lambda x: x[2])

    parent = list(range(n))  # 2. 각 섬의 집합 대표 (자기 자신으로 초기화)

    def find(x):
        # 3. 경로 압축을 적용한 find
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    total = 0
    used = 0
    for a, b, c in costs:
        ra, rb = find(a), find(b)
        # 4. 두 섬이 다른 집합이면 간선 선택 (사이클 방지)
        if ra != rb:
            parent[rb] = ra
            total += c
            used += 1
            # 5. n-1개 간선을 고르면 최소 신장 트리 완성
            if used == n - 1:
                break

    return total
```

### Java

```java
import java.util.Arrays;

class Solution {
    private int[] parent;

    private int find(int x) { // 3. 경로 압축을 적용한 find
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    public int solution(int n, int[][] costs) {
        // 1. 간선을 비용 오름차순으로 정렬
        Arrays.sort(costs, (a, b) -> Integer.compare(a[2], b[2]));

        parent = new int[n]; // 2. 각 섬의 집합 대표 (자기 자신으로 초기화)
        for (int i = 0; i < n; i++) {
            parent[i] = i;
        }

        int total = 0;
        int used = 0;
        for (int[] edge : costs) {
            int ra = find(edge[0]);
            int rb = find(edge[1]);
            // 4. 두 섬이 다른 집합이면 간선 선택 (사이클 방지)
            if (ra != rb) {
                parent[rb] = ra;
                total += edge[2];
                used++;
                // 5. n-1개 간선을 고르면 최소 신장 트리 완성
                if (used == n - 1) {
                    break;
                }
            }
        }
        return total;
    }
}
```

- 막혔던 점: 18:00 자동 풀이로 진행되어 별도의 막힘 없이 풀이했다. 주의할 점은 간선을 비용 순으로 정렬한 뒤에도 사이클 검사가 반드시 필요하다는 것으로, 정렬만으로는 이미 연결된 섬 사이의 간선을 걸러낼 수 없다.
- 핵심 포인트: 간선을 비용 오름차순으로 정렬하고 사이클을 만들지 않는 간선만 고르는 크루스칼 알고리즘과, 집합 소속을 빠르게 판정하는 Union-Find(경로 압축)의 조합이다.
- 개선: 모든 간선 조합을 시도하는 방식 대신 정렬 한 번과 선형 스캔으로 최소 비용을 확정했고, find에 경로 압축을 적용해 집합 판정을 거의 상수 시간으로 만들었다. n-1개 간선을 고르는 즉시 탐색을 멈춰 불필요한 검사를 줄였다.

## 요약

- 모든 섬을 최소 비용으로 연결하는 문제로, 답은 최소 신장 트리의 비용이다.
- 간선을 비용 오름차순으로 정렬하고, Union-Find로 사이클을 만들지 않는 간선만 n-1개 고르는 크루스칼 알고리즘으로 푼다.
- 경로 압축을 적용한 find로 집합 소속 판정을 빠르게 하고, n-1개를 고르는 즉시 탐색을 멈춘다.
- 섬이 1개이면 다리가 필요 없으므로 비용은 0이다.
