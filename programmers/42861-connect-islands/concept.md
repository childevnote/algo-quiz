# 개념 정리: 최소 신장 트리와 서로소 집합

## 1. 최소 신장 트리 (Minimum Spanning Tree, MST)

신장 트리는 그래프의 모든 정점을 연결하면서 사이클이 없는 간선들의 집합이다. 정점이 n개이면 신장 트리는 정확히 n-1개의 간선으로 이루어진다. 최소 신장 트리는 모든 신장 트리 중 간선 비용의 합이 가장 작은 것이다.

- 신장 트리는 "모든 정점을 연결한다"는 조건과 "사이클이 없다"는 조건을 동시에 만족한다. 간선이 n-1개보다 적으면 연결이 끊기고, 많으면 사이클이 생긴다.
- 최소 신장 트리는 유일하지 않을 수 있다. 비용이 같은 간선이 여러 개면 비용 합이 같은 신장 트리가 여럿 존재한다. 이 경우 어떤 것을 골라도 비용 합은 같다.
- 최소 신장 트리는 네트워크 설계, 도로·통신망 연결, 클러스터링 등 "전체를 가장 저렴하게 연결한다"는 문제의 기본 모델이다.

## 2. 크루스칼 알고리즘 (Kruskal's Algorithm)

간선을 비용 오름차순으로 정렬한 뒤, 사이클을 만들지 않는 간선만 차례로 선택하는 탐욕 알고리즘이다.

- 탐욕적 선택이 최적 해를 보장하는 이유는 컷(cut) 성질 때문이다. 정점들을 두 그룹으로 나누는 어떤 경계에 대해, 그 경계를 가로지르는 간선 중 가장 싼 간선은 어떤 최소 신장 트리에도 포함될 수 있다. 크루스칼은 매 단계마다 아직 연결되지 않은 두 집합 사이의 가장 싼 간선을 고르므로, 이 성질을 반복 적용하면 최적 해에 도달한다.
- 동작 순서는 단순하다. 간선을 비용 순으로 정렬하고, 순서대로 살펴보며 양 끝 정점이 이미 연결되어 있지 않을 때만 간선을 선택한다. n-1개를 고르면 종료한다.
- 시간 복잡도는 정렬이 지배적이라 O(E log E)이다. E는 간선 수다.

```python
# 크루스칼 알고리즘의 골격 (일반 그래프, 비용이 작은 간선부터)
edges.sort(key=lambda e: e[2])
for a, b, cost in edges:
    if find(a) != find(b):
        union(a, b)
        total += cost
```

## 3. 서로소 집합 (Disjoint Set Union, Union-Find)

서로 겹치지 않는 집합들을 관리하며, 두 원소가 같은 집합에 속하는지 판정하고 두 집합을 합치는 자료구조다. 크루스칼에서 "이 간선을 고르면 사이클이 생기는가"를 판정하는 데 쓴다.

- 각 집합은 하나의 대표 원소(루트)로 식별한다. `find(x)`는 x가 속한 집합의 대표를 반환하고, `union(a, b)`는 a와 b가 속한 두 집합을 하나로 합친다.
- 두 정점이 같은 집합에 속해 있다는 것은 이미 선택한 간선들로 두 정점이 연결되어 있다는 뜻이다. 이 상태에서 두 정점을 잇는 간선을 추가하면 사이클이 생기므로 버린다.
- 초기에는 모든 원소가 자기 자신만을 원소로 하는 집합이다. 간선을 선택할 때마다 두 집합을 합치므로, 선택한 간선의 수가 늘어날수록 집합의 수는 줄어든다.

```python
parent = list(range(5))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]  # 경로 압축
        x = parent[x]
    return x

def union(a, b):
    parent[find(b)] = find(a)
```

## 4. 경로 압축 (Path Compression)

find 연산 중에 거쳐 간 모든 정점의 부모를 루트(또는 루트에 가까운 정점)로 직접 연결해, 다음 find를 빠르게 만드는 최적화다.

- 경로 압축이 없으면 집합이 한 줄로 길게 이어진 경우 find가 O(n)까지 느려질 수 있다. 예를 들어 1의 부모가 2, 2의 부모가 3처럼 이어지면 루트를 찾는 데 집합 크기만큼의 단계가 필요하다.
- 경로 압축을 적용하면 find를 수행할 때마다 경로상의 정점들이 루트에 직접 붙으므로, 트리가 납작해지고 이후의 find는 거의 상수 시간에 동작한다. 전체 연산의 상각 시간 복잡도는 O(α(n))이며, α는 아커만 함수의 역함수로 실질적으로 5 이하의 작은 값이다.
- 자바의 재귀 구현은 find를 호출하면서 돌아오는 길에 부모를 루트로 갱신하고, 파이썬의 반복 구현은 한 단계씩 건너뛰며 부모를 갱신하는 방식으로 같은 효과를 낸다.

```python
# 경로 압축 전: 1 -> 2 -> 3 -> 4 (루트는 4)
# find(1) 수행 후: 1 -> 4, 2 -> 4, 3 -> 4 (모두 루트에 직접 연결)
```

## 5. 탐욕법 (Greedy)

매 단계에서 당장 가장 좋아 보이는 선택을 하고, 그 선택을 번복하지 않으면서 해를 완성하는 설계 방식이다. 크루스칼은 "지금 고를 수 있는 간선 중 가장 싼 것"을 반복해서 고른다.

- 탐욕법이 통하는 문제는 매 단계의 최적 선택이 전체 최적 해로 이어진다는 성질이 있어야 한다. 모든 문제에 탐욕법이 통하는 것은 아니며, 통하지 않는 문제에서는 동적 프로그래밍이나 탐색이 필요하다.
- 크루스칼에서는 간선을 비용 순으로 보는 순서 자체가 탐욕적 선택이며, 사이클 검사가 "이미 연결된 정점 사이에는 간선을 쓰지 않는다"는 제약을 강제한다. 이 두 규칙이 함께 최소 신장 트리를 만든다.
- 같은 최소 신장 트리 문제의 다른 탐욕 알고리즘으로 프림(Prim) 알고리즘이 있다. 프림은 정점 하나에서 시작해 연결된 정점 집합과 바깥을 잇는 가장 싼 간선을 반복해서 고른다. 크루스칼이 간선 중심이라면, 프림은 정점 중심이다.
