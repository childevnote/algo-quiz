# 해시 — 접두어(접두사) 판정
문제를 푸는 데 필요한 개념만 정리한다. 문제 지문이나 문제 전용 코드는 다루지 않는다.

## 1. 접두어(prefix) 검사
`str.startswith(prefix)`는 문자열의 앞부분이 주어진 부분 문자열과 일치하는지 확인한다. 같은 길이의 문자열끼리 비교하면 동등 여부와 같고, 길이 차이가 나면 접두어 관계가 존재할 수 있다.

## 2. 사전식(lexicographic) 정렬의 성질
문자열을 사전식으로 정렬하면, **서로 접두어 관계에 있는 두 문자열은 정렬 결과에서 반드시 인접하게** 위치한다. 예를 들어 "12", "123", "1235"는 정렬 후 "12"–"123"–"1235" 순으로 붙어 나온다.

왜 그럴까: 두 문자열 A, B가 있고 A가 B의 접두어라면, 어떤 문자열 C가 A < C < B 를 만족할 수 없다. C가 A보다 크면서 A와 다르려면 A가 C의 접두어가 아닌 지점에서 첫 차이가 생기는데, 그 위치에서 B는 A의 뒷부분(접두어가 겹치는 구간)이라 C와 B의 대소 관계가 흔들린다. 접두어 관계의 쌍은 항상 연속된다는 것이 보장된다.

```python
words = ["1235", "12", "567", "123"]
words.sort()
# ["12", "123", "1235", "567"] — "12"-"123"-"1235"는 인접
```

## 3. 접두어 판정의 두 가지 접근
**접두어 해시 방식**: 모든 문자열의 가능한 모든 접두어를 해시 셋에 넣고, 각 문자열이 다른 문자열의 접두어 셋에 들어있는지 확인한다. 시간 O(전체 문자 길이 합), 공간 O(전체 문자 길이 합).

**정렬+인접 비교 방식**: 사전식으로 정렬한 뒤 인접한 쌍만 비교한다. 시간 O(n log n × 비교 비용), 공간 O(n) 또는 제자리 정렬.

두 방식 모두 문제를 해결한다. 정렬 방식은 메모리를 적게 쓰고 구현이 짧다. 접두어 해시 방식은 문자열 길이 합이 크지만 순서 무관하게 한 번의 패스로 끝난다.
