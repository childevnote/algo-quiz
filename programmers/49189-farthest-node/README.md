## 문제 핵심 요약

n개의 노드와 양방향 간선으로 이루어진 그래프에서, 1번 노드로부터 최단 경로(간선 개수 기준)가 가장 긴 노드가 몇 개인지 구하는 문제다. 제한사항: n은 2 이상 20,000 이하, 간선은 1개 이상 50,000개 이하. 예제: n=6, 간선 7개 → 답 3 (4, 5, 6번 노드).

## 문제 분석 및 핵심 로직

1번 노드에서 각 노드까지의 최단 거리를 구한 뒤, 그중 가장 큰 거리와 같은 거리를 가진 노드의 개수를 세면 된다. 모든 간선의 가중치가 1로 같으므로 최단 거리는 너비 우선 탐색(BFS)으로 구한다. 다익스트라를 쓸 이유가 없다.

핵심은 두 가지다.

- **거리 배열로 방문 여부와 거리를 함께 관리한다.** `dist`를 -1로 초기화하고, 처음 도달했을 때만 거리를 기록하고 큐에 넣는다. 이렇게 하면 별도의 visited 배열이 필요 없고, BFS의 레벨 순서 덕분에 처음 기록된 거리가 곧 최단 거리임이 보장된다.
- **최대 거리를 먼저 구하고 개수를 센다.** BFS가 끝나면 `dist`에서 최댓값을 찾고, 그 값과 같은 원소가 몇 개인지 센다. 탐색 도중에 개수를 세려 하면 거리가 갱신될 때마다 다시 세야 하므로, 탐색 완료 후 한 번에 세는 편이 단순하다.

## 개념별 심층 설명

### 너비 우선 탐색(BFS)

큐를 이용해 시작점에서 가까운 노드부터 순서대로 방문하는 탐색이다. 간선 가중치가 모두 같을 때 BFS가 방문하는 순서가 곧 최단 거리 순서가 된다.

- **초심자 방식 — DFS로 거리를 구하려 하기.** 깊이 우선 탐색은 한 갈래를 끝까지 파고들기 때문에 처음 도달한 거리가 최단 거리라는 보장이 없다. 도달할 때마다 더 짧은 거리가 있는지 비교하며 갱신해야 하고, 그래프에 사이클이 있으면 같은 노드를 여러 번 방문하게 된다.
- **개선 방식 — BFS + 거리 배열.** 큐에서 꺼낸 노드의 거리가 이미 최단 거리임이 보장되므로, 이웃을 처음 발견했을 때 기록한 거리는 그대로 확정된다. 각 노드는 큐에 최대 한 번만 들어가고, 각 간선은 최대 두 번(양방향)만 확인하므로 전체 시간은 O(n + m)이다.

BFS의 동작 원리는 이렇다. 시작 노드를 거리 0으로 큐에 넣는다. 큐에서 노드를 꺼내 이웃 중 아직 거리가 정해지지 않은 노드를 거리 +1로 기록하고 큐 뒤에 넣는다. 큐가 빌 때까지 반복하면, 거리가 작은 노드부터 차례로 확정된다. 큐에 들어간 순서가 거리 순서를 유지하기 때문이다.

### 인접 리스트

간선을 인접 리스트로 표현하면 각 노드의 이웃을 바로 순회할 수 있다. 간선이 최대 50,000개이므로 인접 행렬(n² = 4억 칸)은 메모리와 시간 모두 낭비가 크다. 인접 리스트는 간선 수에 비례하는 메모리만 쓴다.

### 거리 배열의 -1 초기화

방문하지 않은 노드를 -1로 표시하면 방문 여부와 거리를 하나의 배열로 처리할 수 있다. `dist[nxt] == -1`이라는 조건 하나로 "아직 방문하지 않음"을 검사한다. 별도의 boolean 배열을 두는 것보다 간결하고, 실수로 방문 표시를 빼먹는 오류도 줄일 수 있다.

## 최종 솔루션 코드

### Python

```python
from collections import deque

def solution(n, edge):
    # 1. 인접 리스트 구성 (양방향 간선)
    graph = [[] for _ in range(n + 1)]
    for a, b in edge:
        graph[a].append(b)
        graph[b].append(a)

    # 2. 1번 노드에서 BFS로 최단 거리 계산
    dist = [-1] * (n + 1)
    dist[1] = 0
    queue = deque([1])
    while queue:
        cur = queue.popleft()
        for nxt in graph[cur]:
            if dist[nxt] == -1:
                dist[nxt] = dist[cur] + 1
                queue.append(nxt)

    # 3. 최대 거리와 같은 거리의 노드 개수 세기
    max_dist = max(dist[1:])
    return sum(1 for d in dist[1:] if d == max_dist)
```

### Java

```java
import java.util.*;

class Solution {
    public int solution(int n, int[][] edge) {
        // 1. 인접 리스트 구성 (양방향 간선)
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) {
            graph.add(new ArrayList<>());
        }
        for (int[] e : edge) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        // 2. 1번 노드에서 BFS로 최단 거리 계산
        int[] dist = new int[n + 1];
        Arrays.fill(dist, -1);
        dist[1] = 0;
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(1);
        while (!queue.isEmpty()) {
            int cur = queue.poll();
            for (int nxt : graph.get(cur)) {
                if (dist[nxt] == -1) {
                    dist[nxt] = dist[cur] + 1;
                    queue.offer(nxt);
                }
            }
        }

        // 3. 최대 거리와 같은 거리의 노드 개수 세기
        int maxDist = 0;
        for (int i = 1; i <= n; i++) {
            maxDist = Math.max(maxDist, dist[i]);
        }
        int answer = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == maxDist) {
                answer++;
            }
        }
        return answer;
    }
}
```

## 요약

간선 가중치가 모두 1인 그래프에서 1번 노드로부터의 최단 거리는 BFS 한 번으로 구한다. 거리 배열을 -1로 초기화해 방문 여부와 거리를 함께 관리하고, 탐색이 끝난 뒤 최대 거리와 같은 노드를 세면 답이 된다. DFS로 거리를 구하려 하면 최단 거리 보장이 없어 같은 노드를 반복 방문하게 되므로, 가중치가 균일한 그래프에서는 BFS가 정석이다.
