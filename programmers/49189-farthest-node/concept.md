# 개념 정리: 너비 우선 탐색(BFS)과 최단 거리

## 너비 우선 탐색(BFS)

그래프를 탐색하는 방법 중 하나로, 시작점에서 가까운 노드부터 순서대로 방문한다. 큐(First In First Out)를 이용해 구현한다.

### 동작 원리

1. 시작 노드를 큐에 넣는다.
2. 큐에서 노드를 꺼내고, 아직 방문하지 않은 이웃 노드를 모두 큐 뒤에 넣는다.
3. 큐가 빌 때까지 2번을 반복한다.

이렇게 하면 시작점에서 거리가 1인 노드들, 거리 2인 노드들, ... 순서대로 방문하게 된다. 같은 거리 그룹 안에서는 큐에 들어간 순서대로 처리된다.

### 일반적인 예시

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    order = []
    while queue:
        cur = queue.popleft()
        order.append(cur)
        for nxt in graph[cur]:
            if nxt not in visited:
                visited.add(nxt)
                queue.append(nxt)
    return order

graph = {1: [2, 3], 2: [1, 4], 3: [1, 4], 4: [2, 3]}
print(bfs(graph, 1))  # [1, 2, 3, 4]
```

## 간선 가중치가 균일할 때의 최단 거리

모든 간선의 비용이 같으면(예: 간선 1개의 비용이 1), BFS가 노드를 처음 방문하는 순서가 곧 최단 거리 순서가 된다. 거리 배열을 -1로 초기화하고 처음 도달했을 때 거리 +1을 기록하면, 그 값이 최단 거리가 된다.

이 성질은 간선 가중치가 다를 때는 성립하지 않는다. 가중치가 다르면 다익스트라 알고리즘처럼 우선순위 큐를 이용해 비용이 작은 노드부터 확정해야 한다.

## DFS와 BFS의 차이

- **DFS(깊이 우선 탐색)**: 한 갈래를 끝까지 파고든 뒤 되돌아온다. 스택(재귀)으로 구현한다. 경로 존재 여부나 연결 요소 탐색에 쓰인다.
- **BFS(너비 우선 탐색)**: 가까운 노드부터 넓게 퍼지며 탐색한다. 큐로 구현한다. 간선 가중치가 균일할 때 최단 거리를 구할 수 있다.

## 인접 리스트와 인접 행렬

그래프를 표현하는 두 가지 방법이다.

- **인접 리스트**: 각 노드마다 연결된 이웃 목록을 저장한다. 메모리 O(n + m), 이웃 순회 O(차수). 간선이 희소한 그래프에 적합하다.
- **인접 행렬**: n × n 표에 간선 유무를 저장한다. 메모리 O(n²), 간선 존재 확인 O(1). 노드 수가 작고 간선이 빽빽한 그래프에 적합하다.

## 시간·공간 복잡도

BFS는 각 노드를 최대 한 번 큐에 넣고, 각 간선을 최대 두 번(양방향) 확인하므로 시간 복잡도는 O(n + m)이다. 인접 리스트와 거리 배열, 큐가 차지하는 공간은 O(n + m)이다.
