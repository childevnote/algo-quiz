# 개념 정리: 너비 우선 탐색(BFS)과 최단 경로

이 문제(단어 변환)를 푸는 데 필요한 개념을 정리한다. 문제 지문, 입출력 예, 문제 전용 풀이 코드는 포함하지 않는다.

## 1. 그래프와 최단 경로

정점(node)과 간선(edge)으로 이루어진 그래프에서 두 정점 사이의 최단 경로는 간선을 가장 적게 거치는 경로이다. 간선의 가중치가 모두 같을 때는 너비 우선 탐색으로 최단 경로를 구할 수 있다.

## 2. 너비 우선 탐색(BFS)

BFS는 시작 정점에서 가까운 정점부터 순서대로 방문하는 탐색 방법이다. 큐(선입선출)를 사용한다.

```python
from collections import deque

def bfs(start, neighbors):
    visited = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for nxt in neighbors(node):
            if nxt not in visited:
                visited.add(nxt)
                queue.append(nxt)
```

시작점에서 거리가 1인 정점들을 모두 처리한 뒤 거리 2인 정점들로 넘어가기 때문에, 목표 정점을 처음 만나는 순간이 곧 최단 거리이다. 간선 가중치가 모두 1일 때만 이 성질이 성립한다. 가중치가 다르면 다익스트라 알고리즘 같은 다른 방법이 필요하다.

## 3. 깊이 우선 탐색(DFS)과의 차이

DFS는 한 경로를 끝까지 파고든 뒤 되돌아와 다른 경로를 탐색한다. 스택(또는 재귀)으로 구현한다. 모든 경로를 열거하거나 연결 요소를 찾는 데 적합하지만, 최단 경로를 구하려면 모든 경로를 비교해야 하므로 BFS보다 비효율적이다.

| 구분 | BFS | DFS |
| --- | --- | --- |
| 자료구조 | 큐 | 스택 / 재귀 |
| 탐색 순서 | 가까운 정점부터 | 한 경로를 끝까지 |
| 최단 경로 (가중치 1) | 보장 | 보장하지 않음 |

## 4. 해시 집합을 이용한 빠른 존재 확인

어떤 값이 집합 안에 있는지 확인하는 연산은 리스트에서는 O(N)이 걸리지만, 해시 집합에서는 평균 O(1)이다. 탐색 과정에서 "이 단어가 허용된 집합 안에 있는가"를 반복해서 물어야 할 때, 집합을 미리 만들어 두면 전체 탐색 시간이 크게 줄어든다.

```python
words = ["apple", "banana", "cherry"]
word_set = set(words)
print("banana" in word_set)  # True, 평균 O(1)
```

## 5. 방문 기록(visited)의 역할

그래프 탐색에서는 같은 정점을 여러 경로로 다시 방문할 수 있다. 방문한 정점을 기록해 두지 않으면 같은 정점을 반복해서 탐색해 시간이 늘어나고, 사이클이 있는 그래프에서는 무한 루프에 빠질 수 있다. 방문 기록은 정점을 큐에 넣는 시점에 남기는 것이 원칙이다. 큐에서 꺼낼 때 기록하면 같은 정점이 큐에 여러 번 들어가게 된다.
