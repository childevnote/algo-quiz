# 개념 정리 — 동적 프로그래밍(격자 DP)과 모듈러 연산

## 1. 동적 프로그래밍(DP)

동적 프로그래밍은 큰 문제를 작은 문제의 답을 이용해 푸는 방법이다. 전제 조건은 두 가지다.

- **최적 부분 구조**: 큰 문제의 답이 작은 문제의 답들로 표현된다.
- **중복 부분 문제**: 같은 작은 문제가 여러 번 등장하므로, 한 번 계산한 답을 저장해 재사용한다.

### 타뷸레이션(표 채우기)

작은 문제부터 순서대로 표를 채워 나가는 방식이다. 재귀 + 메모이제이션(Top-down)과 달리 반복문으로 구현한다.

일반적인 예시 — 피보나치 수:

```python
def fib(n):
    dp = [0] * (n + 1)
    dp[0], dp[1] = 0, 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]
```

각 항이 앞의 두 항만으로 정해지므로, 순서대로 채우면 된다. 점화식의 의존 방향이 한쪽으로만 흐를 때 이 방식이 통한다.

### 격자 DP

2차원 격자에서 한 칸의 답이 이웃 칸의 답으로 정해지는 형태다. 이동 방향이 고정되어 있으면 의존 관계에 사이클이 생기지 않는다. 예를 들어 오른쪽·아래쪽으로만 이동한다면, 어떤 칸의 답은 왼쪽 칸과 위쪽 칸의 답만으로 정해지므로 왼쪽 위부터 오른쪽 아래로 한 번 훑으면 표가 완성된다.

격자 DP의 점화식은 보통 이런 모양이다.

```
dp[y][x] = dp[y-1][x] + dp[y][x-1]        # 경우의 수 합산
dp[y][x] = min(dp[y-1][x], dp[y][x-1]) + cost[y][x]  # 최소 비용
```

### 공간 최적화

현재 행의 답이 이전 행과 현재 행의 왼쪽 값만으로 정해진다면, 2차원 표 전체를 유지할 필요가 없다. 행 하나 분량의 1차원 배열만으로 같은 답을 구할 수 있다.

```python
# 2차원 표 대신 1차원 배열 (dp[x]가 위쪽 값, 갱신된 dp[x-1]이 왼쪽 값)
dp = [0] * (m + 1)
dp[1] = 1
for y in range(1, n + 1):
    for x in range(1, m + 1):
        if x == 1 and y == 1:
            continue
        dp[x] = (dp[x] + dp[x - 1]) % MOD
```

## 2. 모듈러 연산

경우의 수나 큰 정수를 다룰 때, 값이 기하급수적으로 커져 정수 범위를 넘는 것을 막기 위해 매 연산마다 어떤 수 M으로 나눈 나머지를 취한다.

- (a + b) mod M = ((a mod M) + (b mod M)) mod M
- (a × b) mod M = ((a mod M) × (b mod M)) mod M

덧셈과 곱셈은 중간에 나머지를 취해도 최종 결과가 같다. 그래서 매 단계마다 나머지를 취하는 것이 안전하다. 단, 나눗셈에는 이 성질이 그대로 적용되지 않으므로 주의한다.

이 문제에서 M = 1,000,000,007은 소수이며, 프로그래머스·백준 등에서 경우의 수 문제에 관례적으로 쓰이는 값이다.

일반적인 예시:

```python
MOD = 1_000_000_007
a, b = 10**9, 10**9
print((a + b) % MOD)   # 999999993 — 그대로 더하면 오버플로 위험이 있는 언어에서 특히 중요
```

Java에서는 두 int의 합이 int 범위를 넘을 수 있으므로, long으로 더한 뒤 나머지를 취한다.

```java
dp[y][x] = (int) (((long) dp[y - 1][x] + dp[y][x - 1]) % MOD);
```

## 3. 좌표계 주의 — [x, y] vs [행, 열]

격자 문제에서는 좌표의 순서가 문제마다 다르다. 흔한 두 가지 관례는 다음과 같다.

- `[x, y]`: x가 가로(열), y가 세로(행). 수학 좌표계와 같다.
- `[행, 열]`: 첫 번째 값이 행, 두 번째 값이 열. 2차원 배열 인덱스와 같다.

입력이 `[x, y]`인데 배열을 `dp[x][y]`로 잡으면 행과 열이 뒤집힌다. 정사각형 격자가 아닐 때는 인덱스 오류가 나고, 정사각형이면 조용히 틀린 답이 나온다. 좌표를 배열 인덱스로 바꾸는 지점에서 한 번은 순서를 확인하는 습관이 필요하다.
