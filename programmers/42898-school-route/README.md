# 등굣길

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42898
- 레벨: Lv.3
- 카테고리: DP

## 문제 핵심 요약

m × n 격자의 왼쪽 위 집(1, 1)에서 오른쪽 아래 학교(m, n)까지, 오른쪽과 아래쪽으로만 이동해 도달하는 최단 경로의 개수를 1,000,000,007로 나눈 나머지를 구한다. 일부 칸은 물에 잠겨 지나갈 수 없으며, 그 좌표가 `puddles`로 주어진다.

핵심 제한사항:

- m, n은 1 이상 100 이하. m과 n이 모두 1인 경우는 입력으로 주어지지 않는다.
- 물에 잠긴 지역은 0개 이상 10개 이하이며, 집과 학교가 물에 잠긴 경우는 없다.
- 이동은 오른쪽과 아래쪽만 가능하므로, 모든 최단 경로는 정확히 (m − 1)번 오른쪽 이동과 (n − 1)번 아래쪽 이동으로 이루어진다.

입출력 예: m = 4, n = 3, puddles = [[2, 2]] → 4

## 문제 분석 및 핵심 로직

이동 방향이 오른쪽과 아래쪽으로 고정되어 있다는 점이 전부다. 어떤 칸 (x, y)에 도달하는 최단 경로는 왼쪽 칸 (x − 1, y)에서 오는 경우와 위쪽 칸 (x, y − 1)에서 오는 경우로만 나뉘고, 두 경우는 겹치지 않는다. 그래서 각 칸까지의 경로 수는 왼쪽 칸의 경로 수와 위쪽 칸의 경로 수의 합이 된다. 시작점 (1, 1)의 경로 수를 1로 두고 격자를 왼쪽 위부터 오른쪽 아래로 한 번 훑으면, 마지막 칸에 답이 채워진다. 물에 잠긴 칸은 경로 수가 0이다.

좌표계만 주의하면 된다. `puddles`의 좌표는 `[x, y]` 순서인데, x가 열(1..m), y가 행(1..n)이다. 격자를 `dp[y][x]` 형태로 잡으면 puddle의 `[2, 2]`는 `dp[2][2]`가 되고, 집은 `dp[1][1]`, 학교는 `dp[n][m]`이다. 이 순서를 뒤집으면 답이 달라지므로, 문제를 풀기 전에 좌표의 의미를 먼저 확정하는 것이 중요하다.

## 개념별 심층 설명

### 1. 격자 DP — 작은 칸의 답이 큰 칸의 답을 만든다

**초심자 방식: 모든 경로를 직접 세어 본다.**
집에서 학교까지의 모든 경로를 하나씩 열거하면 경로 수는 이항계수 C((m−1)+(n−1), m−1)로, 100 × 100 격자에서는 C(198, 99) ≈ 9 × 10^58에 달한다. 열거 자체가 불가능하다.

**개선 방식: 칸마다 "여기까지 오는 경우의 수"만 기록한다.**
각 칸의 답은 이웃한 두 칸의 답만으로 정해진다. 전체 경로를 세지 않고, 칸을 하나씩 채워 나가면 O(m × n) 시간에 답을 얻는다. 이것이 동적 프로그래밍의 기본형인 타뷸레이션(표 채우기)이다.

**동작 원리.**
dp[y][x] = dp[y−1][x] + dp[y][x−1] (단, 웅덩이면 0).
왼쪽 위부터 순서대로 채우면, 어떤 칸을 계산할 때 그 칸의 위쪽과 왼쪽 칸은 이미 계산이 끝나 있다. 의존 관계가 한 방향으로만 흐르기 때문에 한 번의 순회로 충분하다.

### 2. 모듈러 연산 — 매 단계마다 나머지를 취한다

경로 수는 격자가 커지면 금방 정수 범위를 넘는다. 100 × 100 격자의 답은 이미 10^58 수준이라, 그대로 더하면 오버플로가 난다. 그래서 매 덧셈마다 1,000,000,007로 나눈 나머지를 취한다. 나머지의 덧셈은 (a + b) mod M = ((a mod M) + (b mod M)) mod M 이 성립하므로, 중간에 나머지를 취해도 최종 나머지는 같다. Java에서는 두 수의 합이 int 범위를 넘을 수 있어 long으로 더한 뒤 나머지를 취한다.

### 3. 웅덩이 처리 — 0으로 두는 것이 곧 차단이다

웅덩이 칸의 경로 수를 0으로 두면, 그 칸을 거쳐 가는 경로는 이후의 합에 기여하지 않는다. 따로 "이 칸을 피하는 경로"를 계산할 필요가 없다. 웅덩이가 왼쪽·위쪽 이웃을 모두 막으면 그 뒤의 칸까지 0이 전파되어, 아예 도달할 수 없는 경우도 자연스럽게 0이 된다. 단, 시작점 (1, 1)이 웅덩이인 경우는 입력으로 주어지지 않으므로 따로 처리하지 않았다.

### 4. 공간 절약 — 2차원 표를 1차원으로 줄일 수 있다

이 풀이는 m × n 표를 그대로 쓰지만, 사실 한 행만 유지해도 된다. 현재 행의 dp[x]는 "위쪽 칸의 값(이전 행의 dp[x]) + 왼쪽 칸의 값(현재 행의 dp[x−1])"으로 갱신되기 때문이다. 공간복잡도는 O(m × n)에서 O(m)으로 줄일 수 있다. 이 문제의 제한(m, n ≤ 100)에서는 표를 그대로 쓰는 편이 읽기 쉬워 2차원 표를 유지했다.

## 최종 솔루션 코드

### Python

```python
MOD = 1_000_000_007


def solution(m, n, puddles):
    # 1. 웅덩이 좌표 집합으로 변환 (O(1) 조회)
    puddle = set(map(tuple, puddles))
    # 2. dp[y][x]: (1, 1)에서 (x, y)까지의 최단 경로 수
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    dp[1][1] = 1
    for y in range(1, n + 1):
        for x in range(1, m + 1):
            # 3. 웅덩이면 경로 수 0
            if (x, y) in puddle:
                dp[y][x] = 0
                continue
            if x == 1 and y == 1:
                continue
            # 4. 위쪽 + 왼쪽 경로 수의 합 (mod 적용)
            dp[y][x] = (dp[y - 1][x] + dp[y][x - 1]) % MOD
    return dp[n][m]
```

### Java

```java
class Solution {
    public int solution(int m, int n, int[][] puddles) {
        final int MOD = 1_000_000_007;
        // 1. 웅덩이 여부 표
        boolean[][] isPuddle = new boolean[n + 1][m + 1];
        for (int[] p : puddles) {
            isPuddle[p[1]][p[0]] = true;
        }
        // 2. dp[y][x]: (1, 1)에서 (x, y)까지의 최단 경로 수
        int[][] dp = new int[n + 1][m + 1];
        dp[1][1] = 1;
        for (int y = 1; y <= n; y++) {
            for (int x = 1; x <= m; x++) {
                // 3. 웅덩이면 경로 수 0
                if (isPuddle[y][x]) {
                    dp[y][x] = 0;
                    continue;
                }
                if (x == 1 && y == 1) {
                    continue;
                }
                // 4. 위쪽 + 왼쪽 경로 수의 합 (long으로 더한 뒤 mod 적용)
                dp[y][x] = (int) (((long) dp[y - 1][x] + dp[y][x - 1]) % MOD);
            }
        }
        return dp[n][m];
    }
}
```

## 학습 노트

- 막혔던 점: 없음. 이동 방향이 고정된 격자 DP의 기본형이라 점화식이 바로 보인다.
- 핵심 포인트: dp[y][x] = dp[y−1][x] + dp[y][x−1], 웅덩이는 0. `puddles` 좌표가 [x, y] 순서라는 점만 확인하면 된다.
- 개선: 2차원 표 대신 1차원 배열로 공간을 O(m)까지 줄일 수 있다. m, n ≤ 100이라 이 문제에서는 가독성을 우선해 2차원 표를 유지했다.

## 요약

오른쪽·아래쪽 이동만 가능한 격자에서 각 칸까지의 최단 경로 수는 왼쪽 칸과 위쪽 칸의 경로 수의 합이다. 이 점화식으로 표를 한 번 채우면 답이 나오고, 웅덩이는 0으로 두어 자연스럽게 차단한다. 시간 O(m × n), 공간 O(m × n)이며, 매 단계 모듈러 연산을 적용해 오버플로를 막는다.
