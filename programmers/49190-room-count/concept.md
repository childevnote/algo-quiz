# 개념 정리: 그래프에서 사이클(닫힌 영역) 세기

이 파일은 방의 개수 문제를 푸는 데 필요한 개념만 정리한다. 문제 지문, 입출력 예, 문제 전용 풀이 코드는 다루지 않는다.

## 1. 정점과 간선

그래프는 정점(vertex)과 간선(edge)으로 이루어진다. 정점은 위치, 간선은 두 정점을 잇는 선이다. 간선에 방향이 없으면 무방향 그래프라 부른다. 같은 두 정점을 잇는 무방향 간선은 어느 쪽에서 출발하든 같은 간선이다. 그래서 간선을 기록할 때는 두 정점의 순서를 고정해 하나의 키로 만드는 것이 보통이다. 예를 들어 정점 A와 B를 잇는 간선은 "A-B"와 "B-A"를 같은 키로 취급한다.

```python
# 무방향 간선 키 만들기 (작은 쪽을 앞에 둔다)
edge = (u, v) if u < v else (v, u)
```

## 2. 방문 집합으로 사이클 판정하기

어떤 경로를 따라가며 정점과 간선을 하나씩 기록한다고 하자. 이미 방문한 정점에 도착했는데, 그때 건넌 간선이 아직 기록된 적이 없다면, 그 간선은 기존 경로와 함께 닫힌 고리(사이클)를 만든다. 반대로 이미 기록된 간선을 다시 건너는 것은 고리를 새로 만드는 것이 아니라 이미 있는 선을 되짚는 것뿐이다.

```python
visited_vertices = set()
visited_edges = set()
# 새 정점 v에 간선 e로 도착했을 때
if v in visited_vertices and e not in visited_edges:
    cycles += 1  # 새 사이클이 하나 닫혔다
visited_vertices.add(v)
visited_edges.add(e)
```

이 판정은 경로를 한 번만 훑으면 되므로 전체 과정이 선형 시간에 끝난다.

## 3. 격자 좌표와 대각선 교차

격자 위의 이동은 보통 (x, y) 정수 좌표로 표현한다. 상하좌우 이동은 한 좌표만 1씩 바꾸고, 대각선 이동은 두 좌표를 동시에 1씩 바꾼다.

대각선 이동에는 정점만으로는 잡히지 않는 교차가 있다. (0, 0)에서 (1, 1)로 가는 대각선과 (0, 1)에서 (1, 0)으로 가는 대각선은 어느 정점도 공유하지 않지만, 격자의 한 칸 한가운데에서 만난다. 이런 교차를 정점 기반으로 처리하려면 좌표를 확대하는 방법이 있다. 모든 좌표를 2배로 늘리면 한 칸 이동은 두 칸 이동이 되고, 원래 한 칸 한가운데였던 교차점이 격자 정점이 된다. 구현에서는 좌표를 직접 2배로 하지 않고, 한 번의 이동을 절반씩 두 번으로 나누는 것으로 같은 효과를 낸다.

```python
# 한 칸 이동을 절반씩 두 번 나눈다
for _ in range(2):
    x += dx
    y += dy
    # 이 절반 이동마다 정점·간선을 기록한다
```

## 4. 해시 집합

방문 여부를 빠르게 확인하려면 해시 집합이 쓰인다. 파이썬의 `set`, 자바의 `HashSet`이 대표적이다. 원소의 추가·조회·포함 여부 확인이 평균 O(1)이다. 격자 정점은 (x, y) 튜플, 간선은 두 정점의 순서 없는 쌍으로 표현해 집합에 넣는다. 저장하는 원소 수는 이동 횟수에 비례하므로 공간 복잡도는 O(n)이다.
