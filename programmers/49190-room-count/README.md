## 문제 분석 및 핵심 로직

원점(0, 0)에서 시작해 방향 8개(0=위, 1=오른쪽 위, 2=오른쪽, 3=오른쪽 아래, 4=아래, 5=왼쪽 아래, 6=왼쪽, 7=왼쪽 위) 중 하나로 한 칸씩 이동하며 선을 그린다. 선으로 둘러싸인 영역이 생길 때마다 방 하나가 된다. 방향 배열 `arrows`가 주어지면 방의 개수를 구한다.

핵심은 "방이 생기는 순간"을 판정하는 방법이다. 이미 지나간 정점에 **아직 그은 적 없는 간선**으로 다시 도착하면, 그 간선이 기존 경로와 함께 닫힌 영역을 만든다. 즉, 이동할 때마다

1. 도착 정점이 이미 방문한 정점인지,
2. 이동하려는 간선이 아직 그은 적 없는 간선인지

두 조건을 모두 만족하면 방이 하나 늘어난다. 이미 그은 간선을 되돌아가는 경우는 새 영역을 만들지 않으므로 세지 않는다.

여기서 함정이 하나 있다. 대각선 이동은 격자의 간선 중간에서 교차할 수 있다. 예를 들어 (0, 0)에서 (1, 1)로 가는 대각선과 (0, 1)에서 (1, 0)으로 가는 대각선은 격자 정점을 공유하지 않는데도 중간에서 만난다. 이 교차를 놓치면 방 개수를 틀리게 센다.

### 개념별 심층 설명

**초심자 방식: 정점만 기록하기**

이동 경로상의 정점만 집합에 넣고, "이미 본 정점에 다시 도착하면 방 +1"로 세는 방식이다. 직선 이동만 있는 문제라면 통하지만, 위의 대각선 교차처럼 정점을 공유하지 않고 간선끼리 만나는 경우를 잡지 못한다. 교차점에서 방이 생겼는데도 정점이 겹치지 않았으니 카운트에서 빠진다.

**개선 방식: 간선도 함께 기록하고, 이동을 절반으로 나누기**

두 가지를 바꾼다.

첫째, 정점뿐 아니라 간선도 기록한다. 간선은 양방향이므로 두 정점을 순서와 무관하게 같은 키로 만든다(예: 작은 정점부터 나열). 같은 간선을 다시 그을 때는 방이 생기지 않으므로, 간선 기록이 없으면 되돌아가는 이동을 새 방으로 오판한다.

둘째, 한 칸 이동을 절반씩 두 번으로 나눈다. 대각선 이동 (0, 0) → (1, 1)은 (0, 0) → (0.5, 0.5) → (1, 1)로 쪼개진다. 좌표를 2배로 확대해 정수 격자로 만들면, 두 대각선이 교차하는 지점 (0.5, 0.5)이 격자 정점이 된다. 교차하던 두 간선이 이제 정점을 공유하게 되므로, "이미 본 정점에 새 간선으로 도착"이라는 판정으로 교차에 의한 방도 셀 수 있다. 직선 이동도 동일하게 절반씩 나누면 격자가 일관되게 유지된다.

**동작 원리**

이동 한 번마다 절반 이동을 두 번 수행하고, 각 절반 이동마다 도착 정점과 간선을 검사한다. 정점은 이미 봤는데 간선은 처음 보는 경우에만 방을 하나 더한다. 시작 정점 (0, 0)은 처음부터 방문한 것으로 표시한다. 이 규칙만으로 삼각형, 사각형, 평행사변형, 그리고 대각선 교차로 생기는 방까지 모두 셀 수 있다.

## 최종 솔루션 코드

### Python

```python
def solution(arrows):
    # 1. 방향 0~7에 대한 이동량 (dx: 가로, dy: 세로)
    dx = [0, 1, 1, 1, 0, -1, -1, -1]
    dy = [1, 1, 0, -1, -1, -1, 0, 1]

    # 2. 방문한 정점과 간선 기록 (간선은 방향 없는 키로 저장)
    visited_v = {(0, 0)}
    visited_e = set()
    x, y = 0, 0
    rooms = 0

    for a in arrows:
        # 3. 대각선 교차를 잡기 위해 한 칸 이동을 절반씩 두 번 나눈다
        for _ in range(2):
            nx, ny = x + dx[a], y + dy[a]
            edge = ((x, y), (nx, ny)) if (x, y) < (nx, ny) else ((nx, ny), (x, y))
            # 4. 이미 본 정점에 새 간선으로 도착하면 방 하나가 닫힌다
            if (nx, ny) in visited_v and edge not in visited_e:
                rooms += 1
            visited_v.add((nx, ny))
            visited_e.add(edge)
            x, y = nx, ny

    return rooms
```

### Java

```java
import java.util.*;

class Solution {
    public int solution(int[] arrows) {
        // 1. 방향 0~7에 대한 이동량
        int[] dx = {0, 1, 1, 1, 0, -1, -1, -1};
        int[] dy = {1, 1, 0, -1, -1, -1, 0, 1};

        // 2. 방문한 정점과 간선 기록 (간선은 "작은 정점|큰 정점" 키로 저장)
        Set<String> visitedV = new HashSet<>();
        Set<String> visitedE = new HashSet<>();
        visitedV.add("0,0");
        int x = 0, y = 0;
        int rooms = 0;

        for (int a : arrows) {
            // 3. 대각선 교차를 잡기 위해 한 칸 이동을 절반씩 두 번 나눈다
            for (int i = 0; i < 2; i++) {
                int nx = x + dx[a], ny = y + dy[a];
                String from = x + "," + y;
                String to = nx + "," + ny;
                String edge = from.compareTo(to) < 0 ? from + "|" + to : to + "|" + from;
                // 4. 이미 본 정점에 새 간선으로 도착하면 방 하나가 닫힌다
                if (visitedV.contains(to) && !visitedE.contains(edge)) {
                    rooms++;
                }
                visitedV.add(to);
                visitedE.add(edge);
                x = nx;
                y = ny;
            }
        }
        return rooms;
    }
}
```

## 성능 측정

- 시간 복잡도: O(n) — 이동 한 번마다 절반 이동 2회, 각 이동은 해시 집합 조회·삽입 O(1). n은 arrows 길이.
- 공간 복잡도: O(n) — 방문한 정점과 간선을 각각 최대 2n개까지 저장.

## 학습 노트

- 막혔던 점: 대각선 이동이 격자 정점을 공유하지 않고 간선 중간에서 교차하는 경우를 처음에는 고려하지 않았다. 정점만 기록하면 교차로 생긴 방을 셀 수 없다.
- 핵심 포인트: 방이 생기는 조건은 "이미 본 정점에 새 간선으로 도착"이며, 대각선 교차는 이동을 절반으로 쪼개 교차점을 정점으로 만드는 방식으로 처리한다.
- 개선: 간선을 양방향 키로 기록해 이미 그은 간선을 되돌아가는 이동을 방으로 오판하지 않게 했다.

## 요약

방의 개수는 정점과 간선을 함께 기록하며 세는 문제다. 이미 방문한 정점에 아직 그은 적 없는 간선으로 도착할 때마다 방이 하나씩 늘어난다. 대각선 교차는 한 칸 이동을 절반씩 나누어 교차점을 정점으로 바꾸면 같은 규칙으로 셀 수 있다. 시간·공간 복잡도는 모두 O(n)이다.
