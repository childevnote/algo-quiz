# 개념 노트 — 완전탐색과 주기적 패턴 처리

이 문제(모의고사, 42840)를 푸는 데 필요한 개념만 정리한다.

## 완전탐색 (Brute Force)

모든 가능한 경우를 빠짐없이 시도해 답을 찾는 방법이다. 경우의 수가 많아지면 느려지지만, 이 문제처럼 탐색 범위가 정해져 있고(n ≤ 10,000) 한 경우의 비용이 작으면 충분히 실용적이다. 시간복잡도는 "경우의 수 × 한 경우의 비용"으로 계산한다. 이 문제에서는 경우의 수가 세 사람, 한 경우의 비용이 n번 비교이므로 O(3n) = O(n)이다.

## 나머지 연산(%)을 이용한 주기 처리

길이가 m인 패턴이 무한히 반복될 때, n번째(0-index 기준) 원소는 `pattern[n % m]`이다. 실제 배열을 n 길이로 복제할 필요가 없으며, 공간복잡도를 O(1)로 유지할 수 있다.

```python
# 0, 1, 2, 3, 4, 5, 6, ... 을 주기 3 패턴에서 뽑기
pattern = ["a", "b", "c"]
for n in range(7):
    print(pattern[n % len(pattern)])  # a b c a b c a
```

```java
String[] pattern = {"a", "b", "c"};
for (int n = 0; n < 7; n++) {
    System.out.print(pattern[n % pattern.length]);  // a b c a b c a
}
```

음수 인덱스에서는 언어마다 `%` 결과가 다르니(Java는 음수 나머지를 반환), 인덱스가 항상 0 이상임을 먼저 확인하고 쓴다.
