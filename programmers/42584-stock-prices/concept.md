# 단조 스택 (Monotonic Stack)

## 개념

단조 스택은 스택 안의 원소들이 항상 단조(증가 또는 감소) 순서를 유지하도록 관리하는 스택이다. 원소를 push하기 전에, 단조성을 깨뜨리는 원소들을 먼저 pop한다. "앞뒤로 자신보다 크거나 작은 원소를 처음 만나는 위치"를 찾는 문제에 쓰인다.

## 일반적인 형태

```python
stack = []
for i, x in enumerate(arr):
    while stack and arr[stack[-1]] > x:  # 단조 증가 스택: 큰 원소를 제거
        j = stack.pop()
        # 인덱스 j의 답을 이 시점 i에서 확정
    stack.append(i)
```

위 형태에서 스택 안의 인덱스들은 값이 오름차순(비내림차순)으로 유지된다. 부등호를 `>` 대신 `<`로 바꾸면 내림차순(비오름차순) 스택이 된다. `>`와 `>=` 중 어느 쪽을 쓰느냐는 "같은 값도 제거할 것인가"의 차이이므로 문제 조건에 맞게 선택한다.

## 왜 O(n)인가

각 인덱스는 push를 한 번, pop을 최대 한 번 받는다. while 반복문이 돌 때마다 원소가 하나씩 빠져나가므로 전체 반복 횟수는 n에 비례한다. 이중 반복문처럼 이미 본 구간을 다시 훑지 않는다.

## Java 구현 시 주의점

`java.util.Stack`은 `Vector` 기반의 동기화 클래스라 스레드 경합이 없어도 동기화 비용이 붙는다. 실무적으로는 `Deque<Integer> stack = new ArrayDeque<>();`를 쓰고 `push`/`pop`/`peek` 메소드를 사용한다. (단, `ArrayDeque`는 `null` 원소를 허용하지 않는다.)

## 대표 적용 문제

- 각 원소 뒤에서 처음 등장하는 더 작은 원소까지의 거리 (이 패턴의 문제)
- "오아시스 재결합"처럼 이웃을 세는 문제의 변형
- 히스토그램에서 가장 큰 직사각형: 각 막대를 높이로 하는 최대 너비를 구할 때 왼쪽·오른쪽 경계를 단조 스택으로 찾는다
