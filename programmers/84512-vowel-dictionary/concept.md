# 개념 정리: 트리 전위 순회와 등비수열 합

## 1. 트리의 전위 순회 (Pre-order Traversal)

전위 순회는 노드를 방문한 뒤 자식들을 순서대로 방문하는 탐색 방식이다. 루트를 먼저 방문하고, 첫 번째 자식의 서브트리를 끝까지 탐색한 뒤에야 두 번째 자식으로 넘어간다.

일반적인 예시로, 루트 아래에 자식 B, C가 있고 B 아래에 D, E가 있는 트리를 전위 순회하면 방문 순서는 루트 → B → D → E → C가 된다. B의 서브트리를 다 탐색하기 전에는 C로 넘어가지 않는다는 점이 핵심이다.

```python
def preorder(node):
    visit(node)              # 노드 자신을 먼저 방문
    for child in node.children:
        preorder(child)      # 자식들을 순서대로 재귀 탐색
```

깊이 우선 탐색(DFS)의 한 종류이며, 방문 순서 자체가 의미를 가지는 경우(사전식 나열, 디렉터리 구조 출력 등)에 쓰인다.

## 2. 등비수열의 합

첫째항이 1이고 공비가 r인 수열 1, r, r², ..., rⁿ의 합은 다음과 같다.

```
S = 1 + r + r² + ... + rⁿ = (r^(n+1) - 1) / (r - 1)   (r ≠ 1)
```

예를 들어 r = 5, n = 2이면 1 + 5 + 25 = 31이고, 공식으로는 (5³ - 1) / 4 = 124 / 4 = 31이다.

이 공식은 완전 트리의 노드 수를 셀 때 자주 쓰인다. 각 노드가 r개의 자식을 가지는 트리에서, 깊이가 n까지인 서브트리의 노드 수는 정확히 이 합과 같다. 반복문으로 더하지 않고 한 번의 계산으로 구할 수 있다는 점이 유용하다.
