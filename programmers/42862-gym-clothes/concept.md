# 탐욕법과 집합 차집합

## 1. 탐욕법 (Greedy)

- 매 단계에서 당장 최적으로 보이는 선택을 하고, 그 선택이 전체 최적을 보장할 때 쓰는 기법
- 탐욕이 성립하는 조건: 지금의 선택이 나중의 선택지를 해치지 않아야 한다
- 이 문제의 선택: "번호가 작은 학생부터, 앞번호 이웃에게 먼저 빌린다"
- 왜 앞번호 우선인가: 앞번호 이웃의 여벌은 현재 학생(과 그 앞 학생)에게만 쓸모가 있고, 뒷번호 이웃의 여벌은 뒤쪽 학생에게도 쓸모가 있다. 대체 불가능한(범위가 좁은) 자원을 먼저 소진하면 뒤쪽 선택지가 남는다
- Python 일반 예시 (거스름돈): 동전 종류가 [500, 100, 50, 10]처럼 큰 단위가 작은 단위의 배수일 때, 큰 동전부터 최대한 쓰는 탐욕이 최소 동전 개수를 보장한다
- Java 일반 예시: 위와 같은 거스름돈을 `int[] coins = {500, 100, 50, 10}` 배열로 두고 큰 단위부터 나누어떨어지는 만큼 차감하는 방식

## 2. 집합 차집합으로 상태 정리

- "A에는 있고 B에는 없는 원소"는 차집합으로 한 번에 구한다
- 중복 제거와 O(1) 조회가 덤으로 따라온다
- Python: `only_a = set(a) - set(b)` — 새 집합을 반환하므로 원본이 유지된다
- Java: `a.removeAll(b)` — a 자체를 바꾸므로 원본이 필요하면 `new HashSet<>(a)`로 복사본을 먼저 만든다

## 3. 정렬 기반 탐욕의 복잡도

- 정렬 O(n log n)이 전체를 지배하면 그것이 최종 시간복잡도가 된다
- 정렬 이후의 탐욕 단계가 선형이면 전체는 O(n log n), 추가 공간은 집합 크기만큼 O(n)
- 집합 조회·삭제는 평균 O(1)이므로 선형 탐색 O(n²) 패턴을 대체하는 데 쓴다
