# 개념 정리: 격자 BFS와 좌표 스케일링

이 문제(아이템 줍기)를 푸는 데 필요한 개념을 정리한다. 문제 지문, 입출력 예, 문제 전용 풀이 코드는 포함하지 않는다.

## 1. 격자를 그래프로 보는 관점

2차원 격자는 각 셀을 정점, 상하좌우로 인접한 셀 사이를 간선으로 하는 그래프이다. 격자 위의 이동 문제는 그래프 탐색 문제로 바꿔 생각할 수 있다. 이동할 수 없는 셀(벽, 내부 등)은 정점에서 제외하고, 이동할 수 있는 셀만 남겨 탐색하면 된다.

## 2. 너비 우선 탐색(BFS)과 최단 경로

BFS는 시작 정점에서 가까운 정점부터 순서대로 방문하는 탐색 방법이다. 큐(선입선출)를 사용한다.

```python
from collections import deque

def bfs(start, can_move):
    dist = {start: 0}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for nxt in neighbors(node):
            if can_move(nxt) and nxt not in dist:
                dist[nxt] = dist[node] + 1
                queue.append(nxt)
    return dist
```

모든 간선의 가중치가 1이면, BFS가 목표 정점을 처음 만나는 순간이 곧 최단 거리이다. 가중치가 다르면 다익스트라 알고리즘 같은 다른 방법이 필요하다.

## 3. 좌표 스케일링: 대각선 접촉 문제 해결하기

격자에서 상하좌우 이동만 허용할 때, 대각선으로 맞닿은 두 영역이 인접한 것처럼 보이는 경우가 있다. 예를 들어 두 셀이 대각선 방향으로만 맞닿아 있으면 실제로는 이동할 수 없는데, 격자를 거칠게 그리면 두 셀이 상하좌우로 붙은 것처럼 보일 수 있다.

이럴 때는 좌표를 정수 배로 늘려 격자를 세밀하게 만드는 방법이 있다. 좌표를 2배로 늘리면 원래 한 칸이던 간격이 두 칸이 되어, 대각선으로 맞닿은 지점 사이에는 반드시 한 칸의 틈이 생긴다. 상하좌우 이동만으로는 그 틈을 건널 수 없으므로, 실제로 이어진 경로만 탐색하게 된다. 탐색이 끝나면 거리를 스케일 배율로 나누어 원래 단위로 되돌린다.

## 4. 전처리: 탐색 전에 이동 가능한 영역 표시하기

탐색 알고리즘 자체보다, 탐색할 영역을 정확히 표시하는 전처리가 중요한 경우가 많다. 이 문제처럼 이동 가능한 영역이 도형의 테두리인 경우, 영역을 표시하는 단계와 불필요한 부분을 지우는 단계를 나눠 생각하면 실수를 줄일 수 있다.

- 표시 단계: 이동 가능한 후보 셀을 모두 표시한다.
- 제거 단계: 후보 중 실제로 이동할 수 없는 셀(도형의 내부 등)을 지운다.

두 단계를 분리하면, 표시 단계에서 생긴 여분의 셀을 제거 단계에서 정리할 수 있다. 단, 순서가 중요하다. 제거를 먼저 하고 표시를 나중에 하면, 나중에 표시된 셀이 제거 단계의 효과를 되돌릴 수 있다.

## 5. 방문 기록(visited)과 거리 배열

BFS에서는 이미 방문한 셀을 다시 큐에 넣지 않도록 거리 배열이나 방문 기록을 둔다. 거리를 함께 기록하면, 목표에 도달했을 때 그 거리가 곧 답이 되므로 별도의 경로 추적이 필요 없다. 방문 기록은 셀을 큐에 넣는 시점에 남기는 것이 원칙이다. 큐에서 꺼낼 때 기록하면 같은 셀이 큐에 여러 번 들어가게 된다.
