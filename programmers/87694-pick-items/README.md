# 아이템 줍기

- 문제: [아이템 줍기](https://school.programmers.co.kr/learn/courses/30/lessons/87694)
- 레벨: Lv.3
- 카테고리: DFS/BFS
- 날짜: 2026-11-10

## 문제 핵심 요약

x축, y축에 평행한 변을 가진 직사각형들이 겹쳐진 지형이 주어진다. 캐릭터는 이 지형의 다각형 테두리를 따라서만 이동할 수 있다. 직사각형 목록 `rectangle`, 캐릭터의 시작 위치, 아이템의 위치가 주어질 때, 테두리를 따라 이동해 아이템에 도달하는 가장 짧은 거리를 구한다.

핵심 제한사항:

- 직사각형은 1개 이상 4개 이하이다.
- 모든 좌표값은 1 이상 50 이하의 자연수이다.
- 서로 다른 두 직사각형의 x축 좌표 또는 y축 좌표가 같은 경우는 없다.
- 직사각형이 꼭짓점에서 만나거나 변이 겹치는 경우, 지형이 분리되는 경우, 한 직사각형이 다른 직사각형 안에 완전히 포함되는 경우는 없다.
- 캐릭터와 아이템의 위치는 모두 테두리 위의 한 점이다.

입출력 예:

| rectangle | characterX | characterY | itemX | itemY | return |
| --- | --- | --- | --- | --- | --- |
| [[1,1,7,4],[3,2,5,5],[4,3,6,9],[2,6,8,8]] | 1 | 3 | 7 | 8 | 17 |
| [[1,1,8,4],[2,2,4,9],[3,6,9,8],[6,3,7,7]] | 9 | 7 | 6 | 1 | 11 |
| [[1,1,5,7]] | 1 | 1 | 4 | 7 | 9 |
| [[2,1,7,5],[6,4,10,10]] | 3 | 1 | 7 | 10 | 15 |
| [[2,2,5,5],[1,3,6,4],[3,1,4,6]] | 1 | 4 | 6 | 3 | 10 |

## 문제 분석 및 핵심 로직

이 문제는 테두리라는 1차원 경로 위에서의 최단 거리 문제이다. 이동 가능한 칸이 테두리뿐이므로, 테두리를 정확히 보드에 표시한 뒤 너비 우선 탐색(BFS)을 돌리면 처음 아이템에 도달한 순간의 거리가 곧 최단 거리이다.

핵심 로직은 다음과 같다.

1. 모든 좌표를 2배로 스케일한다. 원래 좌표계에서는 인접한 두 직사각형의 테두리가 대각선으로 닿아 보이는 등, 상하좌우 이동만으로는 구분할 수 없는 지점이 생긴다. 2배 스케일에서는 테두리 사이의 틈이 최소 2칸이 되어, 모서리에서 대각선으로 건너뛰는 이동이 생기지 않는다.
2. 102 × 102 보드에 각 직사각형의 테두리를 표시한다. 직사각형의 네 변에 해당하는 셀을 1로 채운다.
3. 각 직사각형의 내부를 0으로 지운다. 직사각형이 겹치면 한 직사각형의 테두리 일부가 다른 직사각형의 내부에 들어갈 수 있는데, 그 부분은 지형의 내부라 이동할 수 없으므로 지워야 한다. 이 과정을 거치면 겹친 지형의 바깥 테두리만 남는다.
4. 시작 위치에서 BFS를 시작한다. 테두리 셀(값이 1인 셀)로만 이동하고, 각 셀까지의 거리를 기록한다. 아이템 위치에 처음 도달하면 그 거리를 2로 나눈 값이 답이다. 스케일된 좌표계에서 한 칸은 실제 거리의 0.5에 해당하기 때문이다.

## 개념별 심층 설명

### 1. 좌표를 2배로 스케일하는 이유

초심자 방식은 원래 좌표 그대로 격자를 만들어 테두리를 표시하고 BFS를 도는 것이다. 이 방식은 직사각형이 하나일 때는 동작하지만, 두 직사각형이 모서리에서 대각선으로 맞닿는 형태에서는 문제가 생긴다. 원래 좌표계에서는 대각선으로 맞닿은 두 테두리 지점이 상하좌우로 인접해 보여, 실제로는 이동할 수 없는 경로를 BFS가 건너뛰게 된다.

개선 방식은 모든 좌표를 2배로 늘리는 것이다. 원래 좌표 1 단위가 스케일된 좌표 2칸이 되므로, 대각선으로 맞닿은 지점 사이에는 반드시 1칸의 틈이 생긴다. 상하좌우 이동만으로는 그 틈을 건널 수 없으므로, BFS는 실제로 이어진 테두리로만 이동하게 된다. 마지막에 거리를 2로 나누면 원래 단위의 거리가 된다. 이 문제의 제한(좌표 ≤ 50)에서는 보드가 102 × 102로 작아 비용도 크지 않다.

### 2. 테두리 표시 후 내부를 지우는 이유

초심자 방식은 직사각형의 테두리만 골라 표시하면 끝이라고 생각하기 쉽다. 그러나 직사각형이 겹치면 한 직사각형의 테두리가 다른 직사각형의 내부에 들어가는 구간이 생긴다. 그 구간은 겹친 지형의 내부라 캐릭터가 걸을 수 없는 곳인데, 테두리 표시만 해 두면 BFS가 그곳을 통과해 버린다.

개선 방식은 테두리를 표시한 뒤, 각 직사각형의 내부를 0으로 한 번 더 지우는 것이다. 내부에 들어간 테두리 조각이 함께 지워지고, 겹친 지형의 바깥 테두리만 남는다. 테두리 표시와 내부 지우기를 직사각형마다 따로 하지 않고, 모든 직사각형의 테두리를 먼저 표시한 뒤 모든 직사각형의 내부를 지우는 순서가 중요하다. 테두리를 표시하고 곧바로 내부를 지우면, 나중에 표시되는 다른 직사각형의 테두리가 먼저 지워진 내부 위에 다시 그려져 버릴 수 있기 때문이다. 단, 이 방식이 성립하는 것은 문제 조건 덕분이다. 서로 다른 직사각형의 좌표가 겹치지 않고, 한 직사각형이 다른 직사각형 안에 완전히 포함되지 않으므로, 진짜 바깥 테두리는 어떤 직사각형의 내부에도 들어가지 않는다.

### 3. BFS가 최단 경로를 보장하는 이유

테두리 위의 이동은 한 칸씩 상하좌우로만 이루어지며, 모든 이동의 비용이 1로 같다. 이런 그래프에서는 너비 우선 탐색이 시작점에서 가까운 셀부터 순서대로 방문하므로, 아이템에 처음 도달한 순간이 곧 최단 거리이다. 거리를 따로 비교하거나 모든 경로를 열거할 필요가 없다. DFS로 풀면 모든 경로를 끝까지 따라가며 가장 짧은 것을 골라야 하므로, 이 문제에서는 BFS가 맞는 선택이다.

## 최종 솔루션 코드

### Python

```python
from collections import deque


def solution(rectangle, characterX, characterY, itemX, itemY):
    SIZE = 102
    board = [[0] * SIZE for _ in range(SIZE)]

    # 1. 각 직사각형의 테두리를 보드에 표시한다 (좌표 2배 스케일).
    for x1, y1, x2, y2 in rectangle:
        x1, y1, x2, y2 = x1 * 2, y1 * 2, x2 * 2, y2 * 2
        for x in range(x1, x2 + 1):
            for y in range(y1, y2 + 1):
                if x in (x1, x2) or y in (y1, y2):
                    board[y][x] = 1

    # 2. 각 직사각형의 내부를 지운다. 겹친 직사각형의 내부에 들어간
    #    다른 직사각형의 테두리 조각도 함께 지워져 테두리만 남는다.
    for x1, y1, x2, y2 in rectangle:
        x1, y1, x2, y2 = x1 * 2, y1 * 2, x2 * 2, y2 * 2
        for x in range(x1 + 1, x2):
            for y in range(y1 + 1, y2):
                board[y][x] = 0

    # 3. BFS로 테두리를 따라 최단 경로를 탐색한다.
    sx, sy = characterX * 2, characterY * 2
    tx, ty = itemX * 2, itemY * 2
    dist = [[-1] * SIZE for _ in range(SIZE)]
    dist[sy][sx] = 0
    queue = deque([(sx, sy)])
    while queue:
        x, y = queue.popleft()
        # 4. 아이템에 도달하면 스케일된 거리를 2로 나눠 실제 거리를 반환한다.
        if (x, y) == (tx, ty):
            return dist[y][x] // 2
        for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nx, ny = x + dx, y + dy
            if 0 <= nx < SIZE and 0 <= ny < SIZE and board[ny][nx] == 1 and dist[ny][nx] == -1:
                dist[ny][nx] = dist[y][x] + 1
                queue.append((nx, ny))

    return -1
```

### Java

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int solution(int[][] rectangle, int characterX, int characterY, int itemX, int itemY) {
        final int SIZE = 102;
        int[][] board = new int[SIZE][SIZE];

        // 1. 각 직사각형의 테두리를 보드에 표시한다 (좌표 2배 스케일).
        for (int[] r : rectangle) {
            int x1 = r[0] * 2, y1 = r[1] * 2, x2 = r[2] * 2, y2 = r[3] * 2;
            for (int x = x1; x <= x2; x++) {
                for (int y = y1; y <= y2; y++) {
                    if (x == x1 || x == x2 || y == y1 || y == y2) {
                        board[y][x] = 1;
                    }
                }
            }
        }

        // 2. 각 직사각형의 내부를 지운다. 겹친 직사각형의 내부에 들어간
        //    다른 직사각형의 테두리 조각도 함께 지워져 테두리만 남는다.
        for (int[] r : rectangle) {
            int x1 = r[0] * 2, y1 = r[1] * 2, x2 = r[2] * 2, y2 = r[3] * 2;
            for (int x = x1 + 1; x < x2; x++) {
                for (int y = y1 + 1; y < y2; y++) {
                    board[y][x] = 0;
                }
            }
        }

        // 3. BFS로 테두리를 따라 최단 경로를 탐색한다.
        int sx = characterX * 2, sy = characterY * 2;
        int tx = itemX * 2, ty = itemY * 2;
        int[][] dist = new int[SIZE][SIZE];
        for (int i = 0; i < SIZE; i++) {
            for (int j = 0; j < SIZE; j++) dist[i][j] = -1;
        }
        dist[sy][sx] = 0;
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{sx, sy});
        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int x = cur[0], y = cur[1];
            // 4. 아이템에 도달하면 스케일된 거리를 2로 나눠 실제 거리를 반환한다.
            if (x == tx && y == ty) return dist[y][x] / 2;
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx >= 0 && nx < SIZE && ny >= 0 && ny < SIZE
                        && board[ny][nx] == 1 && dist[ny][nx] == -1) {
                    dist[ny][nx] = dist[y][x] + 1;
                    queue.offer(new int[]{nx, ny});
                }
            }
        }
        return -1;
    }
}
```

스케일 테스트는 좌표가 50에 가까운 큰 직사각형 4개로 구성한 합성 입력이다. 직사각형 수와 좌표 범위가 문제 제한의 상한에 가까워, 보드 전체를 채우는 비용이 그대로 드러난다. 예제 케이스 5개는 모두 기대 출력과 일치함을 확인했다.

- 시간 복잡도: O(W × H). W, H는 스케일된 보드의 가로·세로 크기(최대 102)이다. 보드를 채우는 데 O(W × H), BFS도 각 셀을 최대 한 번씩 방문하므로 O(W × H)이다.
- 공간 복잡도: O(W × H). 테두리 보드와 거리 배열이 보드 크기에 비례한다.

## 요약

- 격자에서 이동 경로가 대각선으로 새는 것을 막으려면 좌표를 2배로 스케일해 틈을 벌린다.
- 겹친 직사각형의 테두리만 남기려면 테두리를 먼저 모두 표시한 뒤 내부를 지우는 순서를 지킨다.
- 이동 비용이 균일한 테두리 위의 최단 거리는 BFS로 구하고, 스케일된 거리를 2로 나눠 실제 거리를 얻는다.
- 학습 노트: 이 문제는 BFS 자체보다 테두리를 정확히 그리는 전처리가 핵심이다. 스케일과 내부 지우기 두 단계를 빼먹으면 예제는 통과해도 겹친 직사각형에서 틀린 경로를 찾게 된다.
