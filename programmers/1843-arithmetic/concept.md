# 개념 정리: 구간 DP (Interval DP)

## 구간 DP란

배열이나 문자열의 **구간** `[i, j]`에 대한 답을 구하는 동적 프로그래밍이다. 구간을 더 작은 구간으로 나누고, 작은 구간의 답을 조합해 큰 구간의 답을 만든다.

일반적인 점화식 형태는 다음과 같다.

```
dp[i][j] = combine(dp[i][k], dp[k+1][j])  (i <= k < j)
```

## 채우는 순서

구간 DP에서는 **길이가 짧은 구간부터** 채운다. 길이 `L`인 구간을 계산할 때는 그보다 짧은 구간들의 값이 이미 테이블에 들어 있어야 하기 때문이다.

```python
for length in range(1, n + 1):      # 길이 1부터 n까지
    for i in range(n - length + 1):
        j = i + length - 1
        # dp[i][j] 계산 (길이 < length인 구간은 이미 계산됨)
```

길이 1인 구간(원소 하나)이 기저 조건이 되고, 길이를 하나씩 늘려 가며 전체 구간 `[0, n-1]`까지 채운다.

## 최적 부분 구조

구간 DP가 성립하려면 부분 문제의 최적해가 전체 문제의 최적해를 만드는 구조여야 한다. 즉 구간 `[i, j]`의 답이 그 안의 작은 구간들의 답만으로 결정돼야 한다.

반례: 부분 문제의 최적해만으로는 전체 최적해를 만들 수 없는 경우가 있다. 예를 들어 뺄셈처럼 연산이 단조적이지 않으면, 구간의 최댓값을 구할 때 최솟값도 함께 알아야 한다. 이럴 때는 **저장하는 상태를 늘려서**(최댓값과 최솟값을 둘 다 저장) 최적 부분 구조를 회복한다.

## 시간복잡도

구간이 O(n²)개, 각 구간마다 분할 위치가 O(n)개이므로 전체 O(n³)이다. n이 수백 이하일 때 주로 쓰인다.

## 대표 예시

- 행렬 곱셈 순서: 구간 `[i, j]`의 행렬들을 곱하는 최소 비용
- 팰린드롬 분할: 구간이 팰린드롬인지, 최소 몇 개로 나눌 수 있는지
- 괄호 치기 / 연산 순서: 구간 연산 결과의 최댓값·최솟값
