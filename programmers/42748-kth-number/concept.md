# 슬라이싱과 인덱스 변환, 내장 정렬

## 1. 1-based와 0-based

- 문제 지문은 보통 1부터 세지만, Python/Java의 인덱스는 0부터 시작한다
- 변환 규칙: 시작 인덱스는 1을 빼고, 끝 인덱스는 그대로 둔다
  - 이유: 슬라이스/복사 구간의 끝이 exclusive(끝 미포함)이기 때문
- Python: `items[i-1:j]` → 1-based i번째부터 j번째까지
- Java: `Arrays.copyOfRange(arr, i-1, j)` → 같은 규칙

## 2. 슬라이스는 복사본

- Python의 `items[a:b]`는 원본과 독립적인 새 리스트를 만든다
- 복사본을 정렬해도 원본은 그대로 유지된다
- 여러 번 구간을 잘라야 할 때 원본 보존이 필요한 경우에 활용

## 3. 내장 정렬

- 정렬을 직접 구현(버블·선택 정렬, O(n²))하지 말고 언어의 내장 정렬을 사용한다
- Python: `sorted()` — 새 리스트 반환 / 리스트 `.sort()` — 제자리 정렬
  - 알고리즘: Timsort, 평균 O(n log n)
- Java: `Arrays.sort()` — 기본형 배열은 Dual-Pivot Quicksort, 평균 O(n log n)
- `sorted()`는 새 객체를 반환하므로 원본을 건드리지 않는다

## 4. 시간복잡도

- m개의 구간마다 길이 L을 정렬하면 전체 O(m·L log L)
- 구간이 서로 다르면 전체를 한 번 정렬해 재사용할 수 없으므로 구간마다 정렬이 필요하다
